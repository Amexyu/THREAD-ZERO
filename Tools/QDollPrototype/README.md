# Q 版单姿势原型脚本（程序会话，2026-11-15）

生成 `Artifacts/QDoll/Q版单姿势试验.gif` 的离线脚本，仅作为参考与复现，不参与游戏构建。

- `comp.py`：从 `ArtPack_v08/Source` 的 Heads / Backs / Weapons 源图里切出单件。
- `probe.py`：在 512 画布上叠放身体、头、背包、武器，并把前手盖回武器握把。
- `qdoll.py`：组装 Q 版纸娃娃，提供整体变换（绕脚底旋转、压扁拉伸、平移）。
- `qanim.py`：走路、射击、近战、受击的整体动效与刀光、枪火。

脚本里的路径指向程序会话的临时目录，复现时需要改成本机路径。正式实现会写进 Unity 的 C# 代码。
