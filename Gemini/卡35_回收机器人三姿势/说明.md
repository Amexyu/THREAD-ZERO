## 出图流程

1. Gemini（Mac 上的 Chrome），一章一个对话：先出单只设定图当参考（`参考/ref_<图名>.png`），再在同一个对话里出三姿势横图。
2. 提示词模板（第五章火锅推车原文，其他怪换掉描述和动作）：

> 请用图片生成功能直接出图。新的参考图是第五章的重型小怪「火锅推车重型」：（外形描述）。请照上一张的做法画一张 16:9 横图，从左到右等分三格，画它的三个姿势——①待机：…；②蓄力：…，屏幕上的眼睛眯起来；③出手：…，屏幕上张大嘴大喊。
> 硬性要求：1. 造型、配色、贴纸、画风和参考图完全一致（Q 版、矮胖、粗深色描边、平涂加少量硬边阴影），三格是同一只，只改动作，每格只画一只、不要重复；2. 三个姿势都朝左；3. 三只的轮子底都在同一条水平线上（画面下方 1/8 处），每只在自己那一格里居中，连举起的东西在内高度不超过图高 55%，四周留空，不碰格子边；4. 背景是纯品红色 #FF00FF 平涂，不要地面、地面线、格子分隔线、阴影、光晕、速度线，不要任何文字、字母和数字，也不要给三格加标题（贴纸上只能是星星、爱心、闪电）；5. 机器人身上不要出现品红色和紫色。

   - 身上必须有霓虹粉 / 紫的（霓虹灯泡）：背景改成纯绿 #00FF00，切图加 `--green`。
   - 首领：高度放宽到 70%。
3. 下载：图片右上角「下载完整尺寸的图片」（不是「分享图片」），文件进 `Gemini/_收件箱/出图/`。
4. 切图：`bash take35.sh <图名> [选项]`：把 2 分钟内的最新下载移到 `出图/<图名>_三姿势_原图.jpeg`（已有就加 _2、_3），再跑 `cut35.py`，结果在 `切图/`。
   下载超过 2 分钟的：自己 `mv` 到 `出图/`，再 `python3 cut35.py 出图/<文件> <图名> [选项]`。
5. 检查：`python3 preview35.py 切图/_预览_xx.jpg <图名>...`：左边旧三姿势、右边新三姿势，红线是地面（y=486）。
6. 换进游戏：`cp 切图/*_idle.png 切图/*_windup.png 切图/*_strike.png ../../ThreadZero/Assets/Resources/Art/V16/Enemies/`

## cut35.py 做的事 / 选项

自动：背景统一成纯品红（渐变、阴影也算背景）→ 去地面线 → 去格子分隔竖线 → 去格子边界上的细线 → 每格只留主体（标题字、星星、速度线这类离得远的小碎块刷掉）→ 交给 `Tools/bg/pose_sheet.py`：按旧图 idle 的高度缩放、脚底对齐旧图、三个姿势同一个变换 → 再清一遍离主体 8 像素以外的残渣。

| 选项 | 用途 |
|---|---|
| `--fit` | 有姿势伸出 512 画布时，三格一起缩到刚好放下 |
| `--ground` | 旧图是飘着的、新设计站在地上：三张一起往下挪到 y≈448 |
| `--flip 3` | 第 3 格（或 2,3）画成朝右了，左右翻过来 |
| `--height N` | 新旧外形差太多（旧的宽、新的瘦高）：直接指定 idle 高度 |
| `--align` | 蓄力 / 出手两张的脚底对齐到待机那张 |
| `--green` | 绿底出图 |
| `--spill` | 姿势伸过了格子边界（毛衣针、甩出去的线）：按连通块分格，每格两边多留 8% 宽 |
| `--game` | 直接写进游戏的 Enemies 目录（默认写到 切图/） |

## 每只用的命令

- 默认：swarm、swarm2、swarm3、ranged、ranged3
- `--fit`：brute、brute2、brute3、brute4、brute5、ranged2（用 `_原图_2`）、ranged4、ranged5、swarm4、elite_crusher、elite_hauler、elite_shield（用 `_原图_2`）、elite_carrier、elite_mirror、boss_gatekeeper、boss_crane、boss_watcher、boss_auditor
- `--fit --ground`：elite_beacon、elite_relay、elite_prism
- swarm5：`--fit --ground --flip 3 --height 170 --align`
- elite_protocol：`--fit --green`
- elite_weave：`--fit --spill`
- boss_weaver：`--fit --spill --height 420`（只按旧图高度会太小：旧首领是宽的，新的是瘦高的缝纫机）
