## 第四章（出图_第四章/ → Resources/Art/V16/Stage4/）
配色：象牙白、银蓝镜面（一两道斜高光）、金色描边，点缀琥珀色；天空干净的浅色，脚下是云海（这里从来不下雨）。
- **A 镜面街口 / 空中花园**（4-1、4-2）：远景 = 高矮错落的镜面高楼、金色尖顶 / 光环冠、细白空中连廊、小飞艇、云海里露一点下面的雨城；中景 = 白瓷花坛几何树、镜面灯柱（琥珀灯）、金扶手玻璃栏杆、安保摄像头。
- **B 审计长廊 / 玻璃天桥**（4-3、4-4）：远景 = 几条横跨的玻璃天桥 + 云海裂开一道缝、往下看见暗色的雨城（回收员一路爬上来的地方）；中景 = 审计扫描拱门（琥珀灯带）、金框立镜、白色闸机。
- **C 冷却中枢 / 镜像大厅**（4-5、4-6）：远景 = 云海里一排白色散热塔（金色收口）+ 塔之间结霜的淡蓝冷却管；中景 = 金框镜面墙板 + 白色冷却管 + 冷却机箱。远景头两次写“室内大厅”都画成了带消失点的走廊，改成“像舞台布景一样的平面构图、建筑都是正立面”的室外散热塔才对；它的天空左蓝右白，左右接不上，`C_far_净.png` 按行把两端的色差线性摊平了。
- **D 审计之庭**（4-7 首领）：对称白色大厅，正中椭圆金框大镜子 + 头顶金色光环，大理石审判席，白瓷柱、金纹长幡，两侧琥珀监察灯（动效：两盏灯偶尔闪一下）。
- **地面**（四个场景共用）：白色大理石步道边、金色细线镶边、一排琥珀小灯。

## 第五章（出图_第五章/ → Resources/Art/V16/Stage5/）
配色：石墨黑、深青、青绿色发光线，点缀一点白。上城地板下面、把整座城织在一起的网。
- **A 织网边缘**：远景 = 巨大暗色空腔，顶上一条上城平台底面的剪影，成千上万根线缆垂下来编成网；中景 = 垂到地上的线缆束、编织纺锤柱、深青接线箱（青绿小灯）、倒地的大线轴。
- **B 协议回廊**：远景 = 一整面编织线缆墙，墙里一层层嵌着老式机柜，顶上电缆桥架垂下光纤；中景 = 三个服务器机柜 + 垂下来的线缆束 + 空的守卫充电座。
- **C 母线机房**：远景 = 竖井内壁，几组发光母线排从顶贯穿到底，几圈检修走道；中景 = 母线排插进两个变压罐 + 线轴。
- **D 零号核心**（5-7 首领）：对称圆形大厅，正中悬着一颗线缆编成的心脏一样的核心（青绿光），线缆放射到墙上；两侧编织结构墙和纺锤柱（动效：墙上青绿指示灯闪）。
- 地面沿用游戏里原来的（第二章调青的金属走道）。

## 踩过的坑
- **下载的高清图和聊天里的预览不是同一张**：高清版会把同一个对话里上一张图（或上传的参考图）的内容混进来——第四章 A 中景里混进了整排远景高楼，B 中景的拱门下半截溶进了远景的云和城。办法：**每张中景开一个新对话、不上传参考图**，只用文字写画风（这样出来的高清图是干净的）。A 中景是用预览图的品红遮罩（JS 读预览像素 → 行程编码传出来 → `Tools/bg/mask_from_preview.py`）从高清图里抠出来的。
- 不要用 JS 在页面里建 `<a download>` 下载：Chrome 会把这个站后面的下载都拦住，要刷新页面才恢复。
- Gemini 会给中景画一条地面线：`Tools/bg/kill_ground_line.py` 找整行深色的细线，线和线以下抹成品红。
- 中景物体太小 / 太大：上下补品红或裁掉品红，保持物体底边在图高约 78%（游戏里地面走道上沿的位置）。
- 第五章的怪是石墨黑的，原来的远景太暗（平均亮度 21），怪糊在背景里：装进游戏时给远景整层蒙一层青灰色（原图 × 0.6 + (88,128,124) × 0.4，首领场地 × 0.72），中景不动 → 远景变成中间调，怪和中景都成了清楚的深色剪影（`抠好/` 里是没蒙的版本）。
