# 素材接入检查清单（每次接入前逐条过，不过不进游戏）

1. **朝向**：主角朝右；所有敌人朝左（脸/镜头/胸口/武器朝画面左，背包/背部在画面右）。
   - 主角**每一个部件**都要查朝向，不只是整体：外套身体的圆肩（近侧肩）在画面**左**，拉链 / 门襟 / 领口开口偏画面**右**；和第一章同部位的图并排比一遍。
   - 3/4 侧身时：离观众近、画得更大的那侧肩膀应在画面**右**侧（朝左站）。近侧肩在左 = 朝右 = 不合格。
   - 不合格的处理：能整组水平翻转且翻转后动作仍成立 → 翻转；否则退回重出。**不能带着反向素材进游戏。**
2. **姿势一致**：同一角色的各姿势用的是同一只手/同一件武器；出手方向朝向目标（敌人朝左打）。
3. **手和肢体**：手指、手掌朝向正确，没有断肢、反手、分离的袖管。
   - 主角外套：近侧、远侧两只袖子必须是**两张不同的图**（远侧看内侧、更短更暗），不能用同一张图复制或镜像顶替。
   - 主角外套的「身体」部件**不能自带袖子 / 袖口 / 袖窿洞**（手臂是单独部件）；接入前把手臂、手叠上去看一遍，手要在袖口里。
4. **抠图**：深色底和浅色底各看一遍，没有品红残边、粉色光晕、截平的边缘。
5. **比例与对齐**：放进实际场景预览，和主角同框比较大小，脚底踩在地面线上。
6. 以上每一条在预览图里**逐个敌人/逐张图**确认后，再写进 Resources。
7. **主角部件拼成整个人再看**（卡 32 教训）：
   - 用 `Gemini/卡32_三品牌实装部件/rig_preview.py` 拼一个完整的人，和初始外观并排：头身比、身体高矮、腿长要和游戏里的主角一致（Gemini 爱把身体画高、把腿画长）。
   - 四肢连续：袖子接得上肩膀、手在袖口里、腿接得上衣服下摆，没有断开或错位。
   - 头和身体连着：帽子 / 头盔戴在头上，脸和下巴露出来接到身体上；不要把整个人头装进罩子里、罩子底座压到胸口（用户原话：别整这种「身首异处」的）。
   - 高帽子、头盔放进行动页看一遍：走路上下颠时帽顶不能钻进血条；整备 / 衣柜预览里不出镜框、不压标题。
