# THREAD ZERO：角色重画需求 v0.8（给素材会话）

日期：2026-11-15。作者：程序 / UI 会话（Claude），按用户要求撰写。读者：素材会话（GPT）。
背景：用户对 v0.5 拼装角色和 v0.7 整帧角色的观感都不满意，评价是「AI 味太重」，决定重画角色。敌人贴图不在本次范围内。

## 1. 结论：改成「潮玩公仔 / 可动人偶」风格

不再画精致二次元立绘。角色做成一个机能风的收藏玩偶：比例短、形状大、颜色少、关节和零件分明。

用户最初给的参考游戏《嘣境回收战》就是这个方向。可以参考的气质（只借鉴思路，不复制任何具体角色或设计）：粘土人与 figma 可动手办、乐高小人、搪胶潮流玩具。服装结构请参考真实机能服饰的产品照片（如 ACRONYM、Nike ACG、Y-3 这类品牌的外套、背包、面罩），不要凭空堆绑带。

为什么选它：

1. **AI 味来自细节过多。** 喷枪式渐变光影、满身看不清结构的绑带口袋、通用动漫脸、每帧线条粗细不一。细节越少、规则越死，这些问题越少。
2. **零件分段在玩具上是合理的。** 之前被否决的「分尸感」是把一整件衣服硬切开；公仔的头、背包、武器本来就是独立零件。
3. **四槽真换装变得可行。** v0.7 只有外套能改变角色样子，这是和企划差距最大的地方。公仔方案下头部、背部、武器是刚性零件，画一次就能用在所有姿势上。
4. **和现有界面一致。** 界面是明亮底、近黑色块、单一警戒橙的平面风格，平涂公仔放进去不会像贴图。

## 2. 画风硬规则

以下每条都要能在成图上逐项核对：

| 项目 | 规则 |
|---|---|
| 比例 | 约 2.5 头身；头大、手脚短粗；所有图同一比例 |
| 视角 | 统一 3/4 侧视，默认朝右；所有图同一机位，不许有的偏正面有的偏侧面 |
| 上色 | 纯平涂 + 一层硬边阴影。禁止渐变、喷枪高光、体积光、环境光反射 |
| 颜色数 | 素体不超过 4 种颜色；每件装备不超过 5 种（含一种功能色） |
| 功能色 | 每件装备只用一种亮色点缀（青、荧绿、紫、橙、白之一），面积不超过该件的 15% |
| 描边 | 统一粗细的深色外描边；内部结构线更细，同一张图内不许粗细乱变 |
| 脸 | 两个点状或短横眼睛，没有鼻子和嘴的细节；或者直接被面罩 / 头盔遮住 |
| 细节上限 | 每件装备的小绑带、小口袋、小扣件合计最多 3 处 |
| 辨识度 | 每件装备缩到 64 像素高时，仍能靠轮廓认出是哪一件 |
| 发光 | 不要把光效画进贴图。品质光由程序统一叠加 |

## 3. 结构：素体 + 四层装备

画布沿用现有约定：512×512，朝右，脚底基准为左上原点像素 (256,470)，透明 PNG。

绘制顺序（从后到前）：

1. 背部装备
2. 素体（身体、头、后侧手臂、腿）
3. 外套
4. 头部装备
5. 武器
6. 前侧手（只有手掌，盖在武器握把上）

各层的做法不同，这是本方案能控制工作量的关键：

| 层 | 画法 | 数量 |
|---|---|---|
| 素体 | 每个姿势画一张完整身体，穿基础紧身衣，光头或极短发（让头部装备能套上去） | 4 张 |
| 前侧手 | 每个姿势一张，只画握拳的手 | 4 张 |
| 外套 c0–c4 | 软的，随姿势变形，**每个姿势各画一张**，对齐同姿势素体 | 5 × 4 = 20 张 |
| 头部 h0–h4 | 刚性零件，**只画一张**；程序按每个姿势的头部锚点摆放 | 5 张 |
| 背部 b0–b4 | 刚性零件，只画一张；按背部锚点摆放 | 5 张 |
| 武器 w0–w4 | 刚性零件，只画一张（握把朝下、枪口或刃尖朝右）；按握点和角度摆放 | 5 张 |

合计 43 张。四个姿势：

| 姿势 ID | 内容 |
|---|---|
| `idle` | 待机站姿，武器自然持于身前 |
| `attack_ranged` | 举枪射击，前手平举 |
| `attack_melee` | 挥击 / 突刺的发力瞬间 |
| `hit` | 受击后仰 |

每个姿势需要随图给出 4 组锚点（画布像素，左上原点）：头顶中心、背部挂点、握点、武器角度（度，0 为水平朝右）。量不出来的写 TBD，不要填估计值当实测。

说明：这里的零件摆放针对的是本来就独立的刚性物件（帽子、背包、武器），不是把一件衣服切开旋转。外套始终是按姿势整画的。

## 4. 先做试装包，通过后再铺量

**不要一次画完 43 张。** 第一批只交：

- 素体 4 个姿势 + 前侧手 4 张
- 外套 c0 的 4 个姿势
- h0、b0、w0（枪）、w1（刃）各一张
- 4 个姿势的锚点表
- 一张把以上叠在一起的四姿势合成预览（浅底、深底各一）

共 16 张贴图。程序方接入后截图给用户看，用户确认风格通过，再画其余装备。风格没通过就只返工这 16 张。

## 6. 验收

1. 四个姿势下，素体 + c0 + h0 + b0 + 武器叠在一起：没有穿帮（素体从外套里露出来）、没有悬空零件、武器在手里、前侧手盖住握把。
2. 把 h0 换成任意其他头部、b0 换成任意其他背部：不需要改任何别的图就能对上。
3. 所有图在浅底 #F3F3EF 和深底 #1C1F22 上边缘干净，没有白边和灰底。
4. 第 2 节的规则逐条核对通过。
5. 用户看过游戏内实际画面并确认。在这之前不要标记为完成。
