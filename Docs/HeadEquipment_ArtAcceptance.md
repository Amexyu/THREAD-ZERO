# 头部装备素材验收标准（V08 之后）

## 当前结论

V09 的五款侧视道具叠图已回退。它们虽然换了视角，但没有和原角色的头发、耳位、领口及动作帧成为一张连贯的画。单纯调坐标或缩放不能消除“贴上去”的观感。六帧整图的生成试样也未通过：角色身体被重新绘制，背景不透明，无法替换既有图集。

## 制作基准

- 底稿：`ThreadZero/Assets/Resources/Art/V08/AtlasesFace/Player_c0..c4.png`，每张 1536×1024，3 列 × 2 行，单帧 512×512。
- 帧顺序：0 站立、1 举枪、2 开火、3 近战准备、4 上举、5 前刺。
- 每件头部装备必须提供六帧**仅装备区域**的透明图层。每帧依原画绘制耳位、发际线、下颌、后脑和领口交界；不能把物品图标直接等比缩放。
- 装备遮挡：头带在部分发束下、耳罩在耳位上、护目镜的镜脚进入头发、呼吸面罩的绑带绕向后脑；全罩头盔遮住原脸和原发的对应部分，底缘接入衣领。
- 六帧身体、手和武器轮廓必须与底稿一致；不得重画或移动躯干与四肢，也不得添加背景。
- 头部装备 ID：h0 兜帽、h1 呼吸面罩、h2 护目镜、h3 全罩头盔、h4 猫耳终端。h0 不带猫耳。

## 接入前的检查

1. 对每件装备合成 0–5 帧动画，至少检验 0→1→2→0 与 3→4→5→3；观察头带、耳罩、面罩和衣领是否跳位。
2. 对五套衣服 c0–c4 分别检查帧 0、2、4、5；任何一帧出现浮空、双重头部、旧脸外露、手/剑遮挡错误则拒收。
3. 检查透明边界、单帧 512×512 格线、统一头身比例和画线粗细。
4. 先放暂存区做合成图和动画预览；通过后才更改 `ActorView` 的资源路径或覆盖运行资源。必须保留旧版和版本标识。
