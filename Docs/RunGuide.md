# 运行与验证

## 打开工程

用Unity6000.6.9f1打开`F:\毕业制作\ThreadZero`。打开`Assets/Scenes/Main.unity`，点击播放。若正在播放时脚本更新后显示异常，先停止播放，等待编译完成，再重新播放。

若需要重建场景与窗口设置，使用编辑器菜单 `Thread Zero → Prepare Main Scene`。窗口构建使用 `Thread Zero → Build Windows`。

构建输出为 `F:\毕业制作\Builds\ThreadZero\ThreadZero.exe`。**只有该文件实际生成且构建日志成功，才算已得到可执行版本。**

## 后台验证

- `Tools/TestModel.ps1`：使用编辑器自带 Mono 编译并运行纯 C# 逻辑测试，不启动编辑器。
- `Tools/CompileSources.ps1`：针对本机 Unity API 编译运行时和编辑器源码；不等同于实际引擎运行。
- `Tools/BuildWindows.ps1`：隐藏窗口运行 Unity batchmode，构建 Windows 版本，日志在 `Artifacts/UnityBuild.log`。
- 脚本统一读取ProjectVersion.txt寻找对应安装版本，不再写死旧编辑器路径。工程打开期间后台构建会提示改用现有编辑器的Thread Zero → Build Windows，避免双开同一工程。
- 完整 Unity 环境下，可用 `-executeMethod ThreadZero.Editor.BuildProject.Smoke` 执行隔离的战斗与存档往返/损坏备份恢复检查。

这些脚本不使用桌面自动化，不移动鼠标或修改系统光标。

## 操作（v0.20，2026-11-22 更新）

- 左侧导航四页：行动 / 整备 / 衣柜 / 工坊（数字键 1 2 3 4）。空格暂停，Esc 关弹窗。
- 行动页平时是纯净模式，只看战斗；鼠标移到上下边缘或左侧导航栏，终端界面滑出：选关（关卡名旁边的下拉）、自动推进、倍速、当前配装、最近回收、回收目标。
- 每章 7 关：x-3、x-6 是精英，x-7 是首领；打败首领进下一章（共五章）。倒下维修几秒，开着自动推进会先回刷前面的普通关，战力涨够或刷够次数再自动挑战；在最前面那一关连倒 3 次起会弹卡关提示。
- 整备：比较 / 穿戴 / 分解装备（详情里列基础属性和特殊词条，◆ 是随机词条）、训练、一键分解。左边的义体格子点开可以升级（织网碎片 + 零件），5 件义体的等级加起来就是机械飞升度。
- 衣柜：获得过一次的外观就收藏，分解也保留；幻化只改样子（武器外观只能套在同类武器上：近战配近战、远程配远程）；可以把想要的装备设成回收目标（精英 / 首领 8 次保底）。
- 工坊：升级、重校（换一条词条）、洗炼（锁住想要的，其余重抽）、突破（第四章起，用核心把机密突破成原型）。
- 回声层：打败 1-7 后在选关最下面进入。无尽楼层，每层给织网碎片，每 10 层首领层可选一项「协议异常」，每 25 层里程碑给核心和碎片。
- 离线收益：关掉游戏再打开，按离开时长（最多算 2 小时）× 挂机时的零件收入 × 25% 补零件，弹「欢迎回来」。
- 设置：音效、装备辉光、震屏、自动分解、窗口 / 全屏、立即保存、行动指南。
- 开发用按键：F5 解锁全部关卡，F6 测试战力开关，F8 切换测试 / 正式存档，F9 清空测试存档重开，F3 切换界面配色，F2 给一套测试外观，F4 预览切场动画，F7 机械飞升跳到下一阶段（只在测试存档里，看 30 / 60 / 90 / 100% 的外观）。

## 数据与限制

实际存档位于 Unity 的 `Application.persistentDataPath`，公司名 Ame、产品名 Thread Zero。主档 `thread-zero-save.json`，上一版备份 `.bak`。测试使用 `Artifacts/SmokeSave` 独立目录，不读写用户进度。

界面是 IMGUI（1600×900 逻辑画布，按屏幕等比缩放，比例不同时上下或左右留边）。美术是 Gemini 出图后用 `Tools/bg/` 的脚本处理，出图记录在 `Gemini/` 各张卡里。还没做：日文版、主角飞升阶段的外观、攻击 / 受击音效（现在只有程序生成的提示音）、芯片 / 改装位、图鉴奖励。

在编辑器里可以用 TZ Bridge 自动测试（编译、跑剧本、截图），见 `Docs/TZBridge.md`；数值模拟见 `Docs/数值测试报告.md`（菜单 `Thread Zero → 数值测试 → 立即运行`）。
