**2. 打完主线就没有东西追了**——其实框架都在，只是没接上：

- **回声层**（无尽层）打完第一个首领就开放，但掉落等级锚在第一章（15 + 层数 ÷ 2）。第五章已经掉 70–87 级，回声层要 110–140 层以后才赶得上，所以打完主线去回声层没有收益。
- **许可上限**打完第一个首领就放开到 300 级，后期强化只是花零件，没有新的节点。
- **突破**（机密 + 8 核心 → 原型，补第 5 条词条）有了，但核心来源少、没人提醒。
- **芯片 / 改装位**还没开（工坊里写着"下一步开放"）。
- **义体**每章首领给一件，数值固定，拿到就结束。
- 所有系统差不多一开局就全摆出来了，后面没有"新东西"。

## 二、原则

1. **三层目标同时在**：
   - 分钟级：下一关、下一件掉落、下一次强化。
   - 小时级：下一个首领、下一件义体、新开放的系统。
   - 天 / 周级：深层记录、机械飞升、收集。
2. **刷装备永远有用**（你说的）：卡关时零件、材料带来的稳定成长要占大头，好运气只是让你更快。墙的高度按"普通运气刷多久能过"来定，最倒霉的也别超过两倍。
3. **一关别打太久**（60–120 秒）。慢下来靠"要刷"，不靠"磨血"。
4. **不强制在线**：企划里没有每日任务、体力、强制登录。离线收益照企划做：最多 2 小时、25% 效率、只给零件。
5. **毕业制作的范围**：长线内容靠系统和数值生成，不靠手工做关卡。

## 三、节奏总表（建议）

"最优"是模拟玩家，"普通"是真人挂机（不时时盯着、选装备没那么准），大约慢 1.5–2 倍。

| 阶段 | 最优 | 普通 | 这一段新开放的东西 | 首领奖励 |
|---|---|---|---|---|
| 第一章 | 0:40 | 1–1.5 小时 | 装备、强化、分解、训练 | 绞盘机械臂；**回声层**、许可放开 |
| 第二章 | 1:00 | 1.5–2 小时 | **武器招牌技能**（专属动作）、重校 | 调度义眼 |
| 第三章 | 1:20 | 2–2.5 小时 | **特殊词条**（特装以上）、**洗炼** | 中继脊柱 |
| 第四章 | 1:45 | 2.5–3.5 小时 | **核心与突破**（原型装备） | 冷核心脏 |
| 第五章 | 2:15 | 3.5–4.5 小时 | **芯片 / 改装位**（给技能加元素、吸血） | 织网接口 → 进**零号深网** |
| 主线合计 | 约 7 小时 | 约 11–14 小时（几天） | | |
| 终局 | 无上限 | 无上限 | 零号深网、机械飞升、收集 | |

- 第一章我建议 40 分钟左右（企划写 1.5–2 小时）：第一次打开游戏就该打到第一个首领，拿到第一件义体、看到回声层开放。这是留住人的关键一下，后面几章再逐章拉长。
- 每章比上一章长 1.2–1.4 倍。章内平时关卡平滑，墙放在 x-3（精英）、x-6（精英）、x-7（首领），每堵墙按普通运气刷 15–30 分钟设计。
- 系统按章开放：每一章都有"新东西"，前面也不会一下子太复杂。

## 四、主线之后的长线目标

### 1. 零号深网（把回声层改成终局主线）
- 强度和掉落接着玩家打到的最远一章往上走：打完第五章，第 1 层 ≈ 5-7 的强度，掉落从 88 级起，每两层 +1 级，一直到 300 级（约 420 层）。
- 已有的保留：每 10 层的首领层三选一「协议异常」（厚甲 / 过载 / 狂潮 / 精英化），里程碑给核心。
- 新增：
  - 每 25 层一个里程碑：核心 + 深网材料。
  - 50 / 100 / 150… 层给**深网限定外观**——这游戏本来就是换装，外观是很强的动力。
  - 最高层数挂在地图和标题上。

### 2. 机械飞升度（主轴，接世界观）
- 5 件义体都能升级（1–10 级），用深网材料 + 零件。每级加属性。
- 5 件义体等级加起来就是**飞升度**（满级 50 = 100%）。到 25% / 50% / 75% 时主角外观分阶段机械化：维生面罩 → 义肢、替换关节 → 稳定的机械机体，正好是 16 号定的视觉阶段。100% 给一段尾声。
- 好处：主角"治病 → 换身体 → 飞升"的故事变成玩家实际在追的进度条，外观变化也能看到。
- 现在第五章首领的提示写的是"机械飞升完成"，到时候改成"开始飞升"之类。

### 3. 招牌技能收集
- 每把武器一个招牌技能、一套专属动作（正在做）。高品质 / 原型武器的技能再多一段终结动作。
- "刷到新武器就能看到新招"本身就是收集目标，你 16 号定的规则也是这个意思。

### 4. 图鉴与衣柜
- 集齐一章的一套（5 个部位），或者一个部位的所有品质，给小幅永久加成和称号。外观进衣柜。

### 5. 转生（重置进度换永久加成）——建议先不做
挂机游戏常用来让人"永远有事做"。但这个游戏装备和换装是核心，重置会让人心疼，范围也大。先靠深网 + 飞升；以后觉得深网后期太慢再考虑。

## 五、数值上怎么落实

1. **主线拉长约 3 倍，不靠堆血**：
   - 平时关卡的怪物强度和掉落一起走，保持一关 60–120 秒。
   - 墙（x-3 / x-6 / x-7）比前一关跳一截。
2. **让"刷"稳定有用**：
   - 零件收入和强化、训练的价格重排，让卡在墙上时，花 15–30 分钟的零件能补上约 20–30% 的战力。
   - **掉落保底**：每打 N 次精英 / 首领还没出特装以上，下一次必出。这比削弱敌人更符合"刷装备解决"。
3. **深网**：接上主线的强度和掉落，并定好每 10 层的用时曲线（前 50 层每层几分钟，之后越来越慢）。
4. **用模拟器验收**：每章用时（中位数和最慢种子）、每堵墙要刷多久、深网前 100 层的用时。模拟玩家还要学会突破、升级义体。

## 六、建议的施工顺序

1. **节奏重排**：主线时长、墙、掉落保底、系统按章开放；同时把回声层接上主线变成深网。只改数值和少量代码，影响所有后面的东西，最先做。
2. **技能专属动作**：已开工，震地 / 贯穿突刺 / 回旋切割的动作写好了，等录 GIF 给你验收。
3. **机械飞升**：义体升级 + 外观阶段。先定设计，再出美术（主角分阶段的部件图）。
4. 突破提示、芯片 / 改装位、深网里程碑和限定外观。
5. 离线收益、图鉴奖励。
