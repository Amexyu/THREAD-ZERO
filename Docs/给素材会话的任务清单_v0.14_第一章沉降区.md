## 3. 界面设计（程序方的设计，素材方照此出图）

> **2026-11-16 更新**：§3.3 的“换皮”方案已被否决，布局以 `Review/行动页v3.png` 为准（满屏场景 + 四角 HUD，见 §4.1）。§3.1 的“维生终端”意象与 §3.2 配色仍有效。

### 3.1 概念：一台捡来的、拼凑的维生终端
界面 = 主角随身带的**维生与回收终端**（v0.13 已定）。第一章它是**最破的版本**：

- 外壳是捡来的旧金属件，**屏幕有裂纹、角落贴着胶布、用扎带和管箍固定**；
- 屏幕底色是**深色**（地下没光，终端自己亮）；
- 读数用**维生青绿**，警告和操作用**警戒橙**；
- 以后的章节，终端会随主角身体一起“升级”（裂纹修好、换新外壳）。**这一条只需要现在把“破损装饰”画成独立贴纸**（§4.1 装饰类），方便以后去掉，不要烘焙进框里。

## 4. 素材清单

### 4.1 界面素材（2026-11-16 改：精简 HUD，取代原来的整套 UI Kit）

用户否掉了“铁皮框 + 铆钉 + 胶布 + 大面板”的版本（太臃肿、AI 味和手游味重）。新布局见 `Review/行动页v3.png`（程序方出的草图）：**场景占满全屏，界面只贴四个角**，面板是半透明深色切角小牌子，由程序画。所以**不再需要** 9 宫格面板、按钮四态、舞台铁皮框、破损贴纸。素材方只需要画下面这些：

**A. 小图标**（64×64 透明 PNG，单色线条 + 最多一个功能色，缩到 20 像素仍能认，不要文字）
零件（六角螺母）、核心、地图、设置、帮助、暂停、自动推进、行动、整备、衣柜、工坊；技能“迅切连击”；模块：无人机、标记、电弧、推进、护盾、汲取、处决；属性：生命、攻击、防御、攻速、暴击、幸运。

**B. 头像框（随“机械飞升进度”升档）**
头像框代表主角身体被改造了多少，**只升不降**。分 6 档（0–5），从“血肉 + 旧维生设备”到“完整机体”：

| 档 | 意象 | 画法提示 |
|---|---|---|
| 0 | 缠胶布的旧维生环 | 圆环 + 胶布 + 一根输液管 |
| 1 | 外挂设备 | 加一个夹在环上的小仪表 |
| 2 | 义肢接入 | 环的一侧换成金属段，带接口 |
| 3 | 替换关节 | 一半金属，铆接，开始有指示灯 |
| 4 | 机体化 | 几乎全金属，多个接口与线缆 |
| 5 | 飞升 | 完整机械框，规整、发光点由程序加 |

做法：**一张底环（直径 112，内圈留 96 的头像窗）+ 每档一张叠加装饰层**（同尺寸透明，可叠加），不要每档重画整套。颜色只用中性灰/金属色，青绿与发光由程序叠。

进度来源（程序方定，首版）：机械飞升进度在故事定稿前先按里程碑升档——通过 1-3 精英 → 1 档，通过 1-7 首领 → 2 档；之后每章的精英/首领继续往上，以后工坊的“身体改造”也会加进度。升档时头像框播一次升级动画并弹提示。

**C. 名牌（随当前穿着稀有度变化）**
左下“回收员”名牌，按身上 4 件装备的**平均品质**显示 6 档（量产 → 原型）。会随换装升降。
做法：**一张底牌**（约 330×40 逻辑像素的切角条，9 宫格）+ **每档一个角饰**（贴在名牌左端，约 40×40），越高档越精致（量产：无；改良：一道刻线；特装：铆钉；军规：双刻线+铆钉；机密：小金属翼；原型：断裂纹样）。**颜色一律中性灰**，品质色由程序着色。

**D. 关卡牌与路线管道**
左上关卡牌的底不用画（程序画）。管道上的 7 个阀门给 3 种：普通、精英、首领（首领阀门中间有灯座），每种一张 48×48，状态（已过/当前/未到）由程序着色。

### 4.2 场景背景（4 套）
规格沿用 v0.10/v0.13：每套三层，**左右无缝循环**。

| 层 | 尺寸 | 说明 |
|---|---|---|
| far 远景 | 2560×1080 | 远处的高耸结构、烟雾、远灯；低对比 |
| mid 中景 | 2560×1080，透明底 | 棚屋、管道、栏杆等；透明底 |
| ground 地面 | 1280×300，透明底 | 角色站的地面，可平铺；地面顶边约在第 40 像素，角色脚底在屏幕 78% 高 |
| fore 前景（可选） | 2560×400，透明底 | 偶尔从镜头前经过的管道、铁链、晾晒布；**稀疏**，不能挡住角色 |

（2026-11-16 定：游戏按 **1920×1080** 出图，逻辑画面 1600×900，场景铺满全屏，所以背景是 1080 高。旧的 468 高规格作废。）

| 套 | 名称 | 画什么 |
|---|---|---|
| A | 废液沟渠（1-1、1-2） | 最底层：积水和废液沟、排污管口、潮湿的砖墙、几乎没有天空，只有上方远处的灯。**最暗、烟最浓** |
| B | 叠层棚户（1-3、1-4） | 层层叠叠的棚屋、悬空走道、晾衣绳、管线缠绕；开始能看到上层的灯 |
| C | 泵站管廊（1-5、1-6） | 巨大的管道、阀门、压力表、蒸汽、铁格栅地面；钠灯更多 |
| D | 抽水总闸（1-7 首领） | 一个开阔的机械场地：大闸门、齿轮、水泵；首领战在这里，**可以不循环**，做成 1 屏宽（2048）也行 |

**可读性硬要求（最重要）**：主角穿黑色衣服，场景又是地下，很容易“黑成一片”。所以：
- 角色站立的区域（画面高度 35%–80%）背景要是**中等亮度的烟雾色**（偏灰绿），不要纯黑；
- 背景整体**低对比**，最亮和最暗都放在画面上部和边缘；
- 角色身后不要有高对比的竖线或亮灯；
- 交稿时附一张：角色和敌人放在每套背景上的对照图（用现有 S1 角色和 V07 敌人即可）。

不烘焙发光；烟雾、灯光的光晕如果要做，**单独出一层透明叠加图**，程序控制强弱。

### 4.5 群怪、转场与战斗反馈（2026-11-16 用户追加）

战斗改为**怪物成群涌上来、可以互相重叠**（同屏最多 8 只），关卡之间有转场。因此追加：

| 素材 | 规格 | 说明 |
|---|---|---|
| 小型冲锋怪 | 同 v0.13 §5（idle/windup/wreck 三张），**屏幕高约 140 像素**（比普通怪小一号） | 成群出现、速度快、血少。可以用失控巡逻机缩小改造，但轮廓要和普通巡逻机能分开 |
| 三种怪的分工外形 | 冲锋怪（巡逻机）/ 重型怪（装甲运输机）/ 远程怪（信号干扰机） | 一群怪重叠时也要靠**轮廓**一眼分出谁是谁：冲锋怪矮小前倾、重型怪宽厚、远程怪带天线/发射口 |
| 怪物死亡碎片 | 256×256 每帧，6 帧，白/浅色为主（程序着色） | 必做：一群怪同时死时没有它会很空 |
| 小血条框 | 怪头顶的小血条外框（约 64×8 逻辑像素），橙色系；精英版、首领版各一种更醒目的 | 填充由程序画 |
| 伤害数字底 | 不需要图，程序用字体画；**素材方给一张字体风格参考**（粗、窄、带硬边描边） | 普攻白、暴击橙、技能青绿 |
| 转场：阀门开合 | 一个大阀门轮，透明 PNG 512×512；再给“关闭/打开”两张，程序做旋转 | 关卡结束时阀门转开，代表往上爬一层 |
| 转场：关卡编号底牌 | 9 宫格铁皮牌，约 360×120 逻辑像素，**不要文字** | 程序在上面写“1-3” |

转场流程（程序做，素材方知悉）：最后一只怪倒下 → 主角走出右侧，画面变暗 → 显示章节纵剖面地图，标记往上爬一格、阀门转开、亮出下一关编号 → 画面亮起，新背景，主角从地面检修舱口爬上来（舱盖合上），0.6 秒后第一波怪涌入。约 3 秒。主角在屏幕上固定站在舞台 32% 处。

追加素材：**地面检修舱口**（舱盖打开/关闭两张，约 140×40，透明），按场景 A–D 的地面材质各一套。
