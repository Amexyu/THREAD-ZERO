# 素材接入回执（接续 v0.10 交接）

用户明确要求由素材方直接接入，因此本次修改了运行时代码；原先交接中“不要修改 Scripts”的分工边界以这条用户指示为准。未改 UI 布局、数值、存档或 V07 图像文件。

## 游戏中已经生效

- `ActorView.Player` 在 V07 整帧人物上绘制 V08 独立完整头部。`GameAppAction` 战斗六帧和 `GameApp.PreviewHero` 装备预览均传入当前头部外观 ID。h0 显示新兜帽遮面头，卸下头部装备且无幻化时显示灰发遮面默认头。其它头部 ID 暂以默认遮面头兜底，尚无各自独立图像。
- 为现有整帧人物单独导出了高分辨率的 `Resources/Art/V08/HeadOverlay/{h0,_default}.png`；原 `Resources/Art/V08/Head/` 仍保留 512 画布候选，供后续真正无头身体分层使用。
- `PaperDollView.DrawEquipmentIcon` 对 h0、b0、w0、w1 优先使用 `Resources/Art/V08/EquipmentIcon/<ID>.png`。背包、掉落和装备预览中凡经此函数绘制的四件图标会显示新单件素材；其余 ID 继续使用旧图集。没有更改 UI 结构。

## 尚未替换的游戏世界层

V07 整帧人物中旧枪、旧刀、旧背包已画死。`HybridPreview.png` 的后台合成检查显示直接叠加 w0 和 b0 会出现双武器、双背包，因此世界角色仍使用原整帧内的武器/背包。`HeadSixPreview.png` 是六帧头部覆盖效果检查；有少量旧发梢在兜帽外侧可见，这是混用整帧身体的过渡缺陷。正式解决需完成透明无头、无武器、无背包的身体八帧及锚点后切换 V08 分层。
