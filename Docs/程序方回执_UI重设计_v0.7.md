## 2. 现有 UI 的问题（诊断）

1. **IMGUI 的上限。** `GameApp.cs` 全部用 `GUI.Label` 和纯色矩形 `Box` 画界面：没有图标、字重、描边、过渡动画和悬停反馈。这是调试面板的工具，继续在上面调颜色不会变好。
2. **配色和素材打架。** 装备图标与角色是黑底霓虹画风，现在放在浅灰底上，发光全部被吃掉；整屏又没有任何深色块，画面没有重心。
3. **没有层级。** 标题 29px、正文 13–16px、血条只有 5px 高，所有信息一样轻；行动页中间是六块空白板。
4. **挂机感缺失。** 行动页看不到波次进度、当前配装、刚掉了什么、离目标还差几次，角色旁边没有任何「在变强」的反馈。
5. **从未在 Unity 里看过。** 历史文档里的界面图都是离线渲染器画的复刻图，不是引擎截图；也没有出过新版可执行包。

## 3. 新方向：「明亮底 + 黑色装备块 + 单一警戒橙」

- 页面底色保持明亮（#E8E9E4），符合企划书「比此前明显明亮」。
- 所有放装备图标的格子用近黑色（#1C1F22），让霓虹素材真正发光；品质色只出现在格子底边和文字上。
- 强调色只留一个：警戒橙 #FF4A12。去掉钴蓝，避免和「稀有」蓝混淆。
- 数字和英文标签用 Barlow Condensed，中文用 Noto Sans SC（均为 OFL 许可，可随游戏分发）。
- 导航从底部三个按钮改为左侧黑色竖栏，整备入口带未查看数量角标。

各页要点：

| 页面 | 变化 |
|---|---|
| 行动 | 顶部波次节点（1–4 + BOSS）；敌我血量做成黑色铭牌和分段血条；底部一排：当前配装四格、最近回收六格（只有图标，不是文字日志）、回收目标与保底进度、暂停和 1×/2×/4× |
| 整备 | 三栏：角色与四槽 + 三项大数字属性；五列背包（等级、穿戴中、新、锁定都有标记）；右侧详情直接显示与当前穿戴的差值（▲▼ 加文字，不只靠颜色），随机词条用菱形标在属性行上，不再藏进弹窗 |
| 衣柜 | 左侧大预览与 20 格收集进度；每个部位五张大卡，未收藏显示剪影和产地；定向回收单独成块，8 格保底进度 |

参考取向（只借鉴思路，不复制任何素材或界面）：《明日方舟》《少女前线 2》的工业排版与黑白块面；《命运 2》《暗黑破坏神 IV》的装备对比；《嘣境回收战》以角色穿搭为主角的布局；Melvor Idle 的进度常驻。

## 4. 实现方式（已落地，与最初计划不同）

最初计划用 UI Toolkit。实际改为**继续用 IMGUI，但整套重画**，原因：本会话无法编译，UI Toolkit 需要新增模块、主题文件和字体资源，任何一处写错游戏就起不来；而新设计本身全是直角色块、文字和图标，IMGUI 画得出来，并且只用到工程里已经编译通过的那些接口。等能在 Unity 里实测后，再决定是否迁移到 UI Toolkit。

- `UiKit.cs`：颜色、字体、矩形 / 描边 / 警戒条纹 / 图标 / 按钮 / 装备格。坐标按 1600×900 书写，绘制时换算成屏幕像素；文字按真实像素字号生成，不再靠矩阵放大，所以不会糊。
- 字体：中文用微软雅黑，数字用 Bahnschrift（Windows 自带），缺失时自动退回 Arial。暂时没有打包字体文件。
- 新增表现：血条缓动、伤害数字上浮、掉落图标弹出、整备入口未查看角标、最近回收五格、波次节点、鼠标悬停反馈、背包滚轮滚动。
- 交互变化：随机词条直接标在属性行上（原「随机词条」弹窗取消）；训练按钮移到整备页左下（原「角色属性」弹窗取消）；设置里增加窗口 / 全屏切换；快捷键 空格暂停、1/2/3 切页、Esc 关弹窗。
- 角色仍调用 `CharacterView.Draw`（即被否决的拼装表现），敌人仍是程序画的机器人。这两块等素材方交付后替换，界面不用改。

## 5. 需要素材会话提供的东西

UI 本身的图形（按钮、面板、图标线稿）由程序方用代码和矢量完成，**不需要素材方画 UI 贴图**。需要的是：

| 资源 | 规格 | 用途 |
|---|---|---|
| 20 件装备图标 | 每件单独一张透明 PNG，256×256，主体居中留 8px 边；文件名 `Equipment/<id>/Icon.png` | 背包、衣柜、配装条。现有图集画质可用，只需拆开并统一画布 |
| 角色待机立绘 | 透明 PNG，默认朝右，高度不低于 768px，脚底贴画布底边 | 整备和衣柜的大预览。动画包完成前先用它 |
| 敌人 ×3、首领 ×3 | 透明 PNG，朝左，普通敌人约 400px 高，首领约 560px 高 | 行动页。目前设计稿里是占位框 |
| 行动页背景 ×3（可后置） | 1440×470，明亮、低对比，中间不放高对比物体 | 三个街区各一张 |

没有量测过的锚点请标 TBD，沿用交接说明里的规则。
