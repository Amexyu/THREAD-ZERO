## 给另一 AI 的开场说明（可直接复制）

你负责这个 Unity 6000.6.9f1 Windows 挂机换装游戏的程序、UI 交互、动画播放与引擎集成。另一会话负责全部美术素材与质量检查。请先读企划书和当前 C# 源码，保留装备 ID、实例 UID、纯 C# 规则和存档兼容。当前六部件硬切衣服拼装动画被用户否决，不能照搬为完成版；161 项检查通过仅说明既有逻辑检查通过，不代表美术合格。

你不需要画角色、修肢体或补透明背景。先实现清晰的资源加载和动画事件接口；把你需要的画布、锚点、动作时长、装备层数、Unity 导入约束一次整理成文档，由用户交回素材会话。不要为了适配现有坏图改变核心玩法。用户禁止桌面自动化和鼠标/光标修改。

## 首个素材包范围

先做一套黑青回收员完整角色、一把勤务短铳、一把霓虹切刃，完成待机、枪械攻击、近战攻击、受击、修复。全套联调可用后，再扩展衣服和背部模块。六姿势参考图不作为首个正式包已经完成的证据。

提供文件：PNG 图像、manifest.json、动画时间表、图层排序表、锚点表、浅底/深底边缘检查图、换装试装图、连续播放预览。预览应来自同一批交付素材，不能用另一张概念图代替。

## 接口草案（不是已经量测完成的数据）

- 画布建议 512×512，默认朝右，统一相机。脚底参考建议 `(256,448)`，正式资产须以实际量测为准。
- 所有锚点使用 PNG 左上角为原点的像素坐标。转换为 Unity sprite pivot 时由程序方统一转换，避免混用左上和左下原点。
- 唯一素材 ID 使用 ASCII；装备沿用 w0–w4、h0–h4、c0–c4、b0–b4，不用显示名称当路径或主键。
- 路径例：`Characters/Runner/Idle/000.png`、`Characters/Runner/AttackRanged/000.png`、`Equipment/w0/Icon.png`。这是推荐合同，正式目录由双方固定后不随意重命名。
- 动画逐帧给出 durationMs，不依靠文件名猜播放速度。给 start、release、impact、recover、end 等语义事件；程序方负责映射实际战斗事件。不要把当前原型约 0.28 秒命中时机当成不可调整的美术死约束。
- 动画状态至少 Idle、AttackRanged、AttackMelee、Hit、Repair；如需 Walk、Dash、DeployDrone，程序方先明确使用场景。
- 武器握点、枪口、刃口、背部设备位置与脚底必须标注；没有量测就标 null/TBD，禁止填假坐标称已验证。
- 图标可以统一 128×128；不得直接把缩略图当可穿戴贴图。
- 品质光单独使用 Emission Mask / VFX，不烘焙在基础服装全部帧中；衣柜幻化与实际装备品质分别取值。

建议 manifest 每条记录包含 `assetId`、`version`、`status`（reference / candidate / approved）、`slot`、`templateId`、`animation`、`frames`、`durationMs`、`canvasSize`、`pivotPx`、`anchorsPx`、`layerOrder`、`events` 和 `notes`。当前没有 approved 的新角色动画包。

## 素材质量门槛

角色完整，无肢体脱节、额外手指/手臂、装备悬空、身体缺失、袖子错位；每帧身份、体型和服装结构一致。脚底基准稳定，武器极限动作不裁边。PNG 背景及镂空真实透明，没有半透明灰块、白边或残渣。枪口闪光、斩击轨迹不遮挡手部问题。换至少三种头部/外套/背部组合看连续动作，再批量扩展。

整体图、图标、逐帧动画、可穿戴层、光效遮罩分别验收，不能因为图集上有二十件装备就认定二十件都能穿。程序方发现素材问题应提供有标注的图/视频和资源 ID，素材方修订后提高资产版本。

## 源码现状与边界

`GameModel.cs` 内含 Catalog、物品、属性、装备/衣柜/掉落；`Balance.cs` 为数值来源；`CombatSession.cs` 为自动战斗；`SaveService.cs` 为存档。`GameApp.cs` 是 IMGUI 三页原型。

`DollAnimation.cs`、`PuppetGeometry.cs`、`PaperDollView.cs` 是当前**需要返工的表现实现**，可作为事件接线参考，不能作为美术合格范例。`QualityVisual.cs` 的品质映射可保留，但最终挂点要随新资源更新。

旧资源：RainRunnerAtlas.png、BodyRigAtlas.png、EquipmentAtlas.png。后两者存在角色适配问题；不能未经复核直接扩展。当前程序及文档在 `F:\毕业制作`，测试与预览在 Artifacts。不要向其他 AI 发送真实存档、许可日志或访问令牌。

## 程序方可立刻并行推进

1. 读取当前工程并列出动画/换装导入合同，统一坐标系和路径。
2. 把动画播放与 CombatSession 的逻辑时间分开封装，以事件或明确时间表同步。
3. 保留纯 C# 模型，逐步将 IMGUI 换成分页面正式 UI。
4. 使用稳定占位图验证物品比较、收藏、地图、设置与分辨率适配。
5. 实现丢资源时可定位到 assetId 的错误报告，不静默用几何图形掩盖问题。
