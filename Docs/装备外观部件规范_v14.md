# 装备外观部件规范（v0.14，程序已支持）

换上装备 → 对应部位的外观立刻跟着换；幻化（衣柜里改外观）走同一条路，因为程序读的是 `GameModel.Appearance(槽位)`（已含幻化）。

## 放哪里
每件装备的外观一个文件夹，文件夹名 = 装备 ID：

```
ThreadZero/Assets/Resources/Art/V13/Parts/<装备ID>/part.json
ThreadZero/Assets/Resources/Art/V13/Parts/<装备ID>/<部件>.png
```

缺图的装备不会报错：该部位继续用初始外观（Console 里提示一次 “no layered art for …”）。

## 每个槽位画什么

| 槽位 | 要画的部件 | part.json 字段 |
|---|---|---|
| 头部 h0–h4 | `head` 1 张 | `head` |
| 外套 c0–c4 | `torso` + `arm` 2 张 | `torso`、`arm`（arm 要给 `hand` 手点）；可选 `shoulder` / `shoulderF` |
| 背部 b0–b4 | `pack` 1 张 | `pack` |
| 武器 w0–w4 | `weapon` 1 张 | `weapon`（必须给 `tip`）+ `weapon_class`：`dagger` / `gun` / `heavy` |

腿、手、身体骨架共用初始套装（`Resources/Art/V13/Starter/parts.json`），所以**新部件的尺寸和锚点必须和初始套装同一套比例**（1 单位 = 4 像素；头约 84×76 单位，躯干约 60×50，手臂约 28×40，背包约 34×50，匕首约 14×40）。

## part.json 例子（外套）
```json
{
  "scale": 4,
  "torso": { "file": "torso.png", "pivot": [30, 46] },
  "arm":   { "file": "arm.png",   "pivot": [14, 9], "hand": [14, 29] }
}
```
武器例子：
```json
{ "scale": 4, "weapon_class": "gun", "weapon": { "file": "weapon.png", "pivot": [7, 6], "tip": [7, 38] } }
```

## 动作
- 匕首：普攻前刺；初始匕首（w1 量产）带迅切连击。
- 枪（gun）：抬手射击 + 后坐 + 枪口火光（程序画）。
- 重武器（heavy）：举过头顶下砸。
武器统一画成**握把在上、沿 +y 往下画到尖端/枪口**，`tip` 标尖端/枪口。
