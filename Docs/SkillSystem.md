# 装备技能系统（2026-11-16）

技能来自武器，不是角色固有。系统统一，每件武器只填数据 + 做自己的动作模组。

## 一条技能 = 一条 SkillDef（`Scripts/SkillSystem.cs`）

| 字段 | 含义 |
|---|---|
| trigger | 发动条件，三选一：`Cooldown`（冷却好就放）/ `EveryNAttacks`（每 N 次普攻放一次）/ `Chance`（每次出手按概率，可设保底） |
| cooldown / attacks / chance, pity | 对应条件的参数 |
| duration | 技能动作总时长，期间不普攻 |
| hitTimes / hitDamage | 每段命中时间点与伤害倍率（× 攻击力），段数不限 |
| canCrit | 每段独立判定暴击（默认是） |
| holdOnLowTarget | 目标一刀普攻就倒时不放，留给下一只（默认是） |
| animation | 动作模组 ID，对应 LayeredRigView 里的一套关键帧 + 特效 |

武器登记：`SkillBook.byWeapon`，键 `模板ID|品质`（只限该品质）或 `模板ID`（该模板全品质）。

## 通用规则（所有技能一致，写在 CombatSession，不按武器改）

- 全自动发动：每次可以出手时判断条件；满足就用技能代替这次普攻。
- 技能伤害独立于普攻：不推进“第三击电弧”计数，不吃普攻处决倍率；汲取照常。
- 目标在技能中途死亡：剩余段取消，直接收招；不自动跨目标续击。
- 换装备、被打倒维修：充能/冷却清零，不能带到新武器。
- 充能跨战斗保留（走路、换下一只敌人都不清）。
- 角色脚下显示充能：每 N 次攻击 = 格子；冷却/概率保底 = 进度条；满了变橙。

## 动作：连招动作表（v0.20）

每个技能的动作写在 `Scripts/SkillMoves.cs` 的动作表里：一行一个“拍子”（0..1 的时间点）+ 若干「参数 值」，没写的参数沿用上一拍。
SkillDef 里的命中时刻用 `Beats(时长, 拍子…)` 算，**和动作表里标 ★ 的拍子一一对应，改一边要改另一边**。

- 身体：dx dy sq（压扁）tilt spin（绕腰空翻）face（-1 转身）lean head L Lf
- 武器：A Af（手臂）W（武器角度，可连转多圈）wx wy（抛起来离手）；吊钩：hook（链子方向）reach（链长，负数 = 放到目标的几成）
- 镜头 / 光：zoom（推近）charge（蓄能光）shake（枪身抖）；开关：fx（刃光拖尾）ghost（残影）glint（刃尖一闪）
- 缓动：~lin ~in ~out ~snap；事件：!land !skid !casing !twinkle !thud !residue !steam !fire !fire2（GameAppAction.MoveEvent）
- 命中那一帧的特效、顿帧、震屏按技能写在 GameAppAction.SkillFrameFx；打击感底座在 `Scripts/Impact.cs`。

## 新武器加技能的步骤

1. 在 SkillBook 写一条 SkillDef，选发动条件、填时长 / 命中拍 / 倍率；登记到武器。
2. 在动作表里写一套连招（3～4 个分解动作，身体要大幅移动，武器要有花活），命中拍和 SkillDef 对齐。
3. 在 SkillFrameFx 里给命中帧配特效和顿帧 / 震屏的轻重；需要的话加拍子事件。
4. 用桥接慢放连拍（`set slowMo 0.25` + `burst`）自己先看一遍，再给用户看。
5. 武器外观只能套在同类武器上（近战 / 远程），所以动作只需要和同类武器匹配。
