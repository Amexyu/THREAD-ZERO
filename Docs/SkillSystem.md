# 装备技能系统（2026-11-16）

技能来自武器，不是角色固有。系统统一，每件武器只填数据 + 做自己的动作模组。

## 一条技能 = 一条 SkillDef（`Scripts/SkillSystem.cs`）

| 字段 | 含义 |
|---|---|
| trigger | 发动条件，三选一：`Cooldown`（冷却好就放）/ `EveryNAttacks`（每 N 次普攻放一次）/ `Chance`（每次出手按概率，可设保底） |
| cooldown / attacks / chance, pity | 对应条件的参数 |
| duration | 技能动作总时长，期间不普攻 |
| hitTimes / hitDamage | 每段命中时间点与伤害倍率（× 攻击力），段数不限 |
| canCrit | 每段独立判定暴击（默认是） |
| holdOnLowTarget | 目标一刀普攻就倒时不放，留给下一只（默认是） |
| animation | 动作模组 ID，对应 LayeredRigView 里的一套关键帧 + 特效 |

武器登记：`SkillBook.byWeapon`，键 `模板ID|品质`（只限该品质）或 `模板ID`（该模板全品质）。

## 通用规则（所有技能一致，写在 CombatSession，不按武器改）

- 全自动发动：每次可以出手时判断条件；满足就用技能代替这次普攻。
- 技能伤害独立于普攻：不推进“第三击电弧”计数，不吃普攻处决倍率；汲取照常。
- 目标在技能中途死亡：剩余段取消，直接收招；不自动跨目标续击。
- 换装备、被打倒维修：充能/冷却清零，不能带到新武器。
- 充能跨战斗保留（走路、换下一只敌人都不清）。
- 角色脚下显示充能：每 N 次攻击 = 格子；冷却/概率保底 = 进度条；满了变橙。

## 新武器加技能的步骤

1. 在 SkillBook 写一条 SkillDef，选发动条件、填段数/时间/倍率；登记到武器。
2. 动作模组：rig.py 里加一套关键帧做预览 GIF → 通过后移植到 LayeredRigView（同 animation ID）。
3. 命中时间点必须对准动作里刀刃/弹道真正接触目标的帧。
4. 高品质武器必须有独立动作与特效（见 DaggerSkillProduction_v12.md），不能复用初始三连击。
