# 背景重新设计流程（v0.38，第一到五章全部完成）

用户反馈「照着原来的背景重画，不如按新世界观重新设计」。从 1-1 起改成：每个场景先出一张整体概念图，再按概念图分层生成、做成可平铺的三层背景，动效按新图重新摆位。第一章 A/B/C/D 四个场景已全部换成新设计并在 Mac 版 Unity 实测过。

## 一、流程

1. **概念图**：新对话，上传 1-1 概念图当画风参考（`Gemini/卡34_B晴天涂鸦实装/输入/ref_style_1A.jpg`），写清楚中景、地面、远景各有什么。
2. **分层**：每一层在**新对话**里用纯文字单独生成（在同一个对话里让 Gemini「只要远景」，它会去改上一张图，分不干净）。
   - 远景：不透明。
   - 中景、地面：纯品红 #FF00FF 底，地面上半截全品红。
3. **左右无缝**：`python3 Tools/bg2/tile.py prep 图层.png 输出.jpg --band 0.14`，把输出传回**该图层自己的对话**，让 Gemini 只补中间的绿色竖条；拿回来 `tile.py fit Gemini图 输出.jpg.json 结果.png [--alpha]`。
4. **偏色和渗色**：`bandcast.py`（竖条整体偏品红 / 偏绿时按行校正），`edgeclean.py`（地面带上下沿的品红渗色）。
5. **摆位**：`place.py mid / far / cover`（参数见下表）。地面带直接用原图从「步道后沿」裁到底，缩到宽 1835。
6. **涂鸦**：`decal.py put 图层 贴图 u v 高度 输出 [--rot 度]`，涂鸦素材在 `decals/`（锦鲤、青蛙、太阳、螃蟹、章鱼、海豹、河豚、水獭）。贴在平铺接缝上时先把图层平移半张再贴。
7. **动效**：按新图量位置写 `<场景>_fx.json`（灯、水帘、水面反光、窗里人影、警示灯、蒸汽、水泵道具）。
8. **验收**：`stagemock.py` 先在本地按游戏的平铺方式拼一张整屏预览；部署后用 TZBridge 跑 `ChangeRegion` 截图 + `burst` 连拍看动效。

## 三、踩过的坑

- **补缝时山被一刀切断**：竖条一边是高山、另一边是海，Gemini 常把山画到竖条边上为止。办法：竖条加宽到 0.22，提示里写明「左边的山坡在竖条里逐渐降到海边，右半边只画天空和海」；或者远景本来就大半被中景挡住时，把远景上移，让问题区域藏到中景后面（B 的远景就是这样处理的）。
- **补缝留绿**：Gemini 偶尔只补一部分。`tile.py fit` 会报「竖条里残留的绿色」，大于 0 就重来。
- **两栋楼被画成一栋三种颜色**：提示里写明「竖条左半继续画完左边那栋、右半画完右边那栋，中间用落水管分开，墙色不要渐变」。
- **透视木板出现 V 形**：地面不要用透视木板，改成「正面平视、横向长木板」，接缝最好补。
- **窗玻璃透出品红**：抠图前先把窗格里的粉色重涂成浅蓝玻璃（保留原来的高光走向），不然会被抠成半透明。
- **地面带上沿一条品红线**：裁地面时从品红结束后两三行开始裁，再跑一遍 `edgeclean.py`。

## 四、提示词模板

- 概念图：「请用图片生成功能画一张新图。参考我上传的这张图的画风（明亮晴天的卡通涂鸦风、粗描边、柔和饱和的颜色、干净的平涂），为同一个游戏的下一关画一张新的关卡背景，16:9 横版 2D 卷轴：……。不要人物、动物（涂鸦除外）、文字。」
- 中景：「……中景一层，16:9……画面背景必须是纯品红色 #FF00FF（均匀纯色，不要渐变和阴影）。中景内容：……从画面最左边一直延伸到最右边……底部在画面高度大约 80% 的位置，再往下全是纯品红；顶部以上也全是纯品红。墙上不要涂鸦，不要人物、动物、文字。」
- 地面：「……最前面的一层（地面）……画面上面 50% 必须是纯品红色 #FF00FF……下面 50%：……水面柔和波纹，不要闪光和亮点。」
- 补缝：「用我刚上传的这张图改：这是刚才那张……左右对调以后的样子，中间纯绿色的竖条是缺的部分。请只把绿色竖条补画完整：……要和左右两边对齐、自然连起来，看不出接缝。（品红背景必须保持纯品红 #FF00FF。）绿色以外的地方一点都不要改，画面尺寸和所有东西的位置保持不变，画风一样。」

### 新增的兜底工具（`Tools/bg2/`）

Gemini 补缝这次失败得比第一章多（只补一半、留绿、甚至把旧图又涂绿），按情况换办法：

- `xfade.py in out [--c 300]`：两头交叉淡化，宽度少 c。天空、海面这类没有大物件的远景直接用（B 远景）。
- `periodcut.py in out [--c 120] [--lo 0.7]`：在 0.7W 以后找一个宽度，让开头 c 列和那里最像，裁掉再淡化。警示条、系缆桩、栏杆这种等距的东西会自己对上（B 地面）。
- `holefill.py prep/fit`：补缝补了一半时，把剩下的绿色（扩大一圈）当洞，重新做一张图传回**同一个对话**补洞，拿回来只贴洞里的像素。A 远景的天空就是这样补上的。
- `rowfill.py`：只剩纯天空的行时逐行插值（绿色阈值已改成只认纯绿，不会再把绿色山坡当成没补的）。

### 这次踩过的坑

- **同一个对话里传第二张洞图，Gemini 会回去改第一张**（又画出整条绿竖条）；新开对话补又高又窄的洞，它干脆不补。小洞（云的切边、两个小云尖、树林和山城的分界）最后都是手工处理：云的切边加一个带描边的圆鼓包收圆；小云尖按行插值成天空；树林和山城之间用一条带噪声的弯曲分界线代替竖直羽化。
- **竖条盖掉了原图里的东西**（A 远景的货船船头、吊车臂）：用原图按“不是海面/天空”的像素做蒙版，把船和吊车贴回补好的海面上。
- **Gemini 把东西画出了竖条外**（B 中景顶上那只红集装箱）：fit 的羽化区会把它淡成半透明。重新对齐 Gemini 原图，在那几行里直接取它的像素（集装箱左端完整了）。
- **有规律的结构补歪了**（C 中景的桁架、C 地面的斜条纹）：桁架按“整跨”从别的跨镜像拷贝过来，接缝藏在柱子后面；斜条纹在左右两边各找相位最像的位置，拉伸 1.4% 重采样过去。
- **品红渗进补的区域**：桁架镂空、墙顶出现紫色时，按行判断这一行在竖条外是“镂空行”（改透明）还是“实心行”（改成本行中位色），再跑一次 `bandcast.py --sigma 5`。
- **吊着的东西用 lift 会和钢缆脱节**：lift 是整张图往下移，钢缆顶端会离开横梁。改用 swing，支点放在图顶（pivotV 0），顶端对准横梁中间。
- **中景宽超过 2048 会被压小**（meta 里 maxTextureSize 2048）：B 先按 s 1.25 摆出来是 2294 宽，后来改成 s 1.1（2019 宽），整个龙门吊也进了画面。
- **信号灯**：Gemini 把红灯绿灯都画亮了，用 blinks 在红灯和绿灯位置各放一个、相位差 0.5，就变成红绿交替。

### 新工具和新参数

- `quiltcut.py in out [--c 260] [--lo 0.75]`：像 periodcut 一样找宽度，但重叠区按“最小误差边界”逐行走一条弯曲切线，不做交叉淡化。屋顶这类杂乱纹理几乎看不出接缝（B 远景）。
- `tile.py fit … --union 160`：Gemini 把东西画出竖条外时（原图那里透明），把和竖条内容连在一起的那块整块取过来，不会被羽化成半透明。
- `tile.py fit … --rows 0.26-0.78`：Gemini 在品红区乱加东西（比如在下面复制了一排房子）时，只用这几行做对齐。
- `tile.py fit … --cut`：竖条两边不做线性羽化，改成逐行找两边最像的弯曲切线，两边内容不同时不会有重影（A 中景）。
- `Tools/bg2/tile.py`、`decal.py` 的 `key2` 引用改成 `Tools/bg/key2.py`（原来指错了目录，在 Mac 上直接跑会报错）。

### 这次踩过的坑

- **概念图要求正侧面平视**：B 第一版天桥是斜透视的，重画时要写“横向笔直、和画面底边平行、不要透视”。第二次重画的说法换了一下，Gemini 第一次回“没办法提供帮助”，加上“请用图片生成功能”就好了。
- **中景上方出现淡淡的“幽灵”图案**（A 中景的晒衣绳、水塔）：抠图后把最高天线以上的行全部清空。
- **格栅孔里透出品红**（B 地面）：在格栅那几行把品红色像素改成深灰。
- **补的远景两次都只补了一小块**（B 远景）：不再找 Gemini，直接 `quiltcut.py`。
- **Gemini 在铁丝网上留下品红细线**（B 中景竖条）：在栏杆那几行把粉色像素改成深色铁丝，再去品红边。

### 新工具和新动效

- `mkbase.py far / mid / ground`：Gemini 原图一步做成补缝前的底图（缩到宽 1835；中景顺带 key2 抠图 + 紫边去色；地面自动从品红结束处裁）。
- `persprect.py in out --rows y0-y1`：地砖被画成一点透视时，自动找竖缝、拟合消失中心，逐行横向缩放把竖缝拉直。A 地面拉正后地砖间距 231，正好是玻璃护栏立柱间距的一半，`periodcut.py` 一次就对上。
- `StageFx` 新增 `bubbles`：`u0..u1 × v0..v1` 的竖条里小气泡往上冒、左右晃、到顶变淡（`count`、`speed` = 图层高度 / 秒）。老配置不受影响。
- 风扇做法和第三章卷盘一样：拟合风扇外圈的浅色圆环找圆心（误差 < 1 像素），从 Gemini 原图（分辨率更高）按圆心切 256×256 的圆盘当轮子，半径比黑色描边圈小 2 像素，转起来描边不动。

### 新做法

- **灯泡 / 灯笼的光晕**（`mkbase.py mid --glow`）：Gemini 把白色光晕画在品红底上，抠图后变成一团粉色。按「绿通道 = 白光比例」反混合成半透明暖白光（A）。墙是淡紫色、灯笼是粉色时（B）加 `--glowt 45`：只取和透明处连着的偏品红块，先开运算断开描边缺口，不会把粉灯笼当成光晕。
- **纺车轮转起来**（C）：拟合轮辋内圈找圆心和半径（≈81 像素）；轮辋内「不是墙色、银色窗框、透明、毛线」的像素都算辐条和轮毂，切成 `C_spokes*.png`（只有辐条，外面透明）当道具转（60–85 度 / 秒）；中景图里把辐条抹掉（`cv2.inpaint`，颜色和透明度都补），轮辋留在图上不动——圆环转不转看不出来。
- 星星、灯泡、灯笼都用 `lamps`（白天配色下只有中间一个小亮点在呼吸，偶尔闪一下），不用 `blinks`（blinks 有黑色灯座，适合指示灯）。

### 这次踩过的坑

- **补缝区上半没补、留着绿色**（A 中景）：先把 Gemini 图里成块的纯绿改成品红再对齐；竖条上沿还画了两条竖线，单独清掉。
- **Gemini 在云带下面补了一整块白色**（A 中景）：云带以下用左边原图同一行的云边整段替换。
- **拱门下面的台基被补成了缺口**（B 中景）：从没有柱脚的台基里取一段 170 像素，横向重复补上。
