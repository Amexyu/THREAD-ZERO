> 后续评审：用户认为当前拼装角色像“分尸”，此动画表现已被否决，不能作为合格素材继续扩展。新的 v0.6 协作分工和素材门槛见《THREAD_ZERO_完整企划书.md》《AI协作交接与素材接口.md》。本文保留为历史改动记录，编译和逻辑检查不证明画面质量。

更新：2026-11-15。

## 界面

采用浅灰白底、石墨文字、钴蓝标识与安全橙色的机能工坊视觉。行动页使用仓库结构线、分区编号与地面警戒涂装。保留行动、整备、衣柜三个独立页面；属性、地图、设置继续按需弹出。品质文字使用深色墨色，发光仍使用原品质亮色，保证浅底可读。

## 动作和命中

- 射击：抬臂瞄准、枪口闪光与弹道、后坐、收枪，基础动作约 0.56 秒。
- 近战：后撤蓄力、举刃、向前挥击、弧形轨迹、收招，基础动作约 0.68 秒。
- 头、躯干、双臂、双腿均参与姿态；衣袖跟随手臂，武器绑定手部。上身部件共用躯干父变换，避免转体时脱节。
- 战斗以不超过 0.05 秒子步推进动画。伤害在攻击启动后约 0.28 秒结算，受到子步量化；不再在抬手之前扣血。提高攻速会提前进入下一次动作。
- 暂停冻结动作；换装、换区、修复时清理不兼容的待命中状态。仅普通攻击启动角色攻击动画，无人机等模块攻击保持独立。

## 验证与复现

`Tools/TestModel.ps1`：161 项检查通过，涵盖贴图映射、武器持续握持、枪口随转体移动、攻击前摇与命中时机，以及原有存档和掉落规则。

`Tools/CompileSources.ps1`：对 Unity 6000.6.9f1 的运行时与编辑器 API 编译通过。

`Tools/RenderV5.ps1`：生成 ActionUiV5Review.png、OutfitsV5.png、AttackFramesV5.png、AttackAnimationV5.gif。GIF 为可解码的 36 帧循环。角色预览与 Unity 共用 PuppetGeometry 和 DollAnimation；UI 静图是离线复刻布局，均不作为 Unity 运行截图或录屏。

`Tools/GenerateBalanceReport.ps1`：已加入新的动画时机依赖并重新生成模拟结果；数值基准没有为视觉更新额外增强。

## 尚待游戏内验收
