# 装备技能与机械飞升：用户确认方向

日期：2026-11-16。此文记录用户最新决定，优先于 v0.11 中“四肢永远不动”的攻击规范。角色移动仍用灵动的小幅蹦跳，攻击必须有完整手臂动作与正确握持。

## 世界观

主角身患疾病，为了生存进入封锁区回收机械零件，逐步修复、替换身体，最终实现机械飞升。具体疾病名称、病因和结局细节暂未确定。角色不是天生具有战斗技能的人，战斗能力来自实际安装、穿戴的装备。

先用现有人物验证匕首动作；后续角色素材要匹配这个故事，不能将当前健康、完整机能服形象视为最终默认形象。

2026-11-16 用户已认可新图《街头维生拾荒者》作为初版造型；以 `CharacterVisualBaseline_v12.md` 为视觉基准，后续不再沿用此前健康机能服样稿作为新资产的默认人物。

后续视觉提案：初期为维生面罩、旧衣物与少量外置设备；中期体现义肢、替换关节与接口；后期体现稳定的机械机体。保持全遮脸、Q版机能风与衣柜辨识度。以上阶段是待设计方案，不是已完成资产。疾病暂不做持续掉血、限时死亡等强迫玩家在线的惩罚。

## 装备技能

- 武器类别决定普攻动作，具体武器附带招牌技能；换掉实际武器即更换相应技能，不设置角色固有主动技能树。
- 初始匕首：普攻短刺，附带“迅切连击”。此三连击仅属于初始匕首，不能作为后续所有稀有度匕首的通用技能。此前首轮样稿曾称 w1 霓虹切刃；该历史称呼不代表已将它确定为初始装备，不改稳定装备ID与存档，具体映射由程序方核对现有目录后落表。角色用惯用手持械，另一只手始终在胸前护位，不握短刀柄。
- 迅切连击：向前斜切敌人躯干、反向回切、收刀后前刺，三段各有独立命中事件。第一刀刃路经过前方目标胸腹，不能朝地面或自身膝部下扎。暂定三次各80%攻击力，冷却5秒，动作约0.7秒；数值待程序方模拟与试玩。普通攻击与技能各用独立动作。
- 技能动作占用普攻时间，不与普攻同时播放；冷却与普攻攻速分别控制。当前敌人在连击中死亡，停止剩余段并收招，首版不自动跨目标续击。
- 割裂、弱点刺杀为后续匕首模板的备选招牌技能，当前不批量制作。
- 重型破拆器另做长重武器与双手蓄力动作；不能把当前短刀双手下劈算作合格匕首模组。
- 芯片/改装件为装备技能增加电弧、汲取等效果；不因每种元素重做整个身体动作。具体装备的技能与固有效果需由程序方统一表述，避免旧“处决”与新技能重复叠乘。
- 用户于2026-11-16明确：后续其他稀有度的匕首技能必须配套独特动作模组和特效。上述芯片规则只描述同一技能的改装，不允许用“初始三连击+换色特效”代替另一件高稀有度武器的招牌动作。
- 幻化先限制在同武器类别，不能持重锤外观播放匕首动作。
