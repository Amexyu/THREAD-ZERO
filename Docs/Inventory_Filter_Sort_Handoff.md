# 装备筛选与排序交接

2026-11-15。用户本轮明确要求直接完成筛选和排序，因此本次在 Claude 现有整备 UI 内接入功能，未重设计三栏布局、色彩、角色或战斗。

## 已实现

- 保留部位标签；背包上方增加排序字段、升降序、可折叠筛选、清空筛选。
- 排序：获得顺序、稀有度、等级、生命、攻击、防御、攻速、暴击、幸运。属性按单件装备实际总属性（含随机词条）排序；无虚构战力评分。
- 筛选：名称或装备模板 ID 搜索、五档品质多选、等级上下限、已穿戴/未穿戴/已锁定/未锁定、随机词条类型、固定效果。
- 同类品质取并集，不同筛选条件取交集。词条匹配真实 affixes，不把基础属性误算为随机词条。等级边界包含；反向区间提示错误并显示零结果。空等级默认为 1–100。
- 同排序数值按等级、品质、最近获得稳定排序。获得顺序使用原 items 索引，不使用 UID 推断时间。不原地重排 items，不修改存档结构。
- 查询是独立纯 C# InventoryQuery；后续词条系统可以在此扩展。当前随机词条为单类型匹配，尚未做多词条 AND/OR 或词条数值阈值。
- 筛选条件切换重置滚动，显示结果数和空结果提示；点击穿戴槽和掉落“查看”清空筛选以显示目标装备。清空筛选保留当前排序。查询选项只保留本次运行，不写入存档。

## 改动文件

- 新增 Assets/Scripts/InventoryQuery.cs：筛选与稳定排序。
- 新增 Assets/Scripts/GameAppInventory.cs：与现有 Ui 配色一致的工具条和展开面板。
- GameAppLoadout.cs：调用查询和动态调整背包裁剪区域；穿戴槽点击重置查询。
- GameApp.cs：OpenItem 重置查询。
- Tests/InventoryQueryTests.cs、Tools/TestInventory.ps1：独立查询回归测试。
