# 双向接敌与近身实时战斗

2026-11-16，用户要求先做移动，地图另做。双方都主动移动、接近后持续战斗，去掉站在两端和每次出刀冲过去再退回原位的表现。

## 本轮行为

- 敌我各自拥有世界位置和移动速度，同时接近，而非轮流行动。角色加速至220、敌人至160逻辑像素/秒，接近结束时限制步长防止穿过对方。
- 普通近战脚底锚点间距176；精英188、Boss200。此距离已包含当前角色与敌人的绘制尺寸，接触时刀尖可达到目标边缘，不代表两个图片中心完全重合。
- 远程角色可在更远150像素的位置停下射击，敌人继续接近至自身近战距离；不会一直隔着半个屏幕对射。
- 进入各自射程才开始攻击。双方攻击计时独立，敌人的攻击可以在匕首连击中结算，没有轮次占有权。装备远程模块在接敌前也不提前杀死远处敌人。
- 贴身后保持实际位置，播放昨天的普攻/三连击。删除运行模式中每个攻击周期的长距离前冲和退回起点。
- 前排倒下时，下一只保持其后方真实位置，双方再接近，上一目标剩余连击不能跨距离打下一只。
- 一波结束后，下一波出现在角色前方，角色不重置回屏幕起点；镜头跟随角色前进，现有背景随镜头滚动。只保留Boss回入口与街区转移的旧过渡，地图重新设计尚未进行。
- 行进继续使用整角色轻微前倾、小幅蹦跳与落地压缩，头、手、刀在相同整体变换下运动；不增加四肢摆腿或新的拼装骨骼。
- 敌人有对应的向左移动倾斜/跳动，近身攻击时用短小姿态反馈。仍用旧敌人素材，不宣称已完成新的怪物动作帧。残骸降低高度，避免仍像站着的敌人。

## 接入位置

- `EncounterMovement.cs`：纯C#位置、加速、距离、防重叠、镜头和新目标推进。
- `CombatSession`：射程决定攻击、模块触发，死亡/换目标取消旧动作；`GameApp.Awake`明确启用移动。
- `GameAppAction`：使用模拟的实时坐标绘制角色、敌人、血条与效果，按移动距离驱动跳动。
- `GameApp.Update`：常规换波直接进入新接敌，不再播放暂停战斗的固定行进片段。地图精修不在本轮范围。
- 初始匕首隔离测试局不再将敌人设为不死和禁止攻击，直接Play即可观察完整接敌与战斗。只有传入自动截图参数时保留高血量测试靶。

## 验证与边界

- `Tools/TestMovement.ps1`：19项移动专项，覆盖双方同时移动、未到射程不伤害、接触后位置稳定、独立攻击、敌人贴近远程、下一成员接敌、下一波不回原位、大步长不重叠与暂停。
- 既有161项模型检查、18项匕首检查通过；运行时、UNITY_EDITOR条件分支和编辑器代码独立编译通过。合计198项逻辑检查。
- `Tools/RenderMovementReview.ps1`：用同一CombatSession/EncounterMovement和实际Runtime图集离屏渲染10秒预览；不是Unity实机截图。模拟中144帧双方移动、91帧近身，击败5个目标。
- `Artifacts/Movement_CloseCombat.gif` 为本地离屏预览，不提交约30MB的测试动图。仓库中的 `Deliverables/ArtPack_v12/Review/Movement_Contact_QA.png` 提供接敌/接触对照。
- 尚缺用户Mac或正常桌面会话中的Unity实机验收，后台许可IPC限制没有被当作已解决。现有BalanceReport仍是旧静态计时基线，不用它声称新接敌距离的节奏已平衡。
- 当前仍仅初始匕首整套新造型通过动作方向确认；自由换装分层、地图美术与高稀有度技能继续留待后续。
