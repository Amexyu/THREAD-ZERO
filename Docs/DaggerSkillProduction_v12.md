# 匕首技能制作约定

2026-11-16 用户最新要求。本文件覆盖旧文档中与以下决定相冲突的描述，不代表程序、技能资源已经完成。

## 已确定的规则

1. 角色没有固有主动技能；技能来自实际装备。
2. 单手匕首普通攻击为一次短促前刺。初始匕首的装备技能是“迅切连击”：斜切→回切→终结前刺。三连击不能作为全部匕首的默认技能。
3. 后续其他稀有度匕首的招牌技能必须有独特动作模组和配套特效，形成刷到新装备的可见反馈。只增加伤害、只换发光颜色、只替换刀贴图均不满足此要求。
4. 共用角色骨架、基础护位和类别普攻是允许的；招牌技能的蓄力、攻击轨迹、节奏、命中次数/时点及收招需要按具体技能设计。不能给同一动作改名就视为独特模组。
5. 芯片可为同一招牌技能添加元素/汲取等效果，不必重做该技能所有身体动作；这不替代另一件高稀有度装备本身的独特招牌动作。

## 初始三连击的动作约束

- 相机和面向固定，三段攻击指向前方同一个目标，左手保持胸前护位。
- 第一刀从肩前切入前方目标的胸腹，动作要读作刃部划切。出刀末端不能把持刀手垂到大腿，再以刀尖向地面下扎。
- 第二刀从第一刀末端反向上切；肩、肘、腕连续，刀柄随手，不能换手、出现第三只手或把护手放到背后。
- 第三刀屈肘收至腰侧，蹬地送髋送肩，伸肘前刺至目标胸腹，立即屈肘收刀。不能只有武器平移。
- 当前预览18个绘制姿势，680ms循环；慢放2040ms。两者均含准备与收招时间，不是最终战斗事件表。
- 三段命中应各有事件，以实际刀刃接触姿势校准。原暂定伤害、冷却不在本轮修改，不能将预览帧时长直接当作程序已接入的事实。

## 后续五档的制作要求

沿用现有普通/精良/稀有/史诗/传说五档。以下是制作要求，不是已批准的招式名称或数值表。

| 档位 | 技能动作 | 技能特效与反馈 |
|---|---|---|
| 初始匕首 | 本轮迅切连击，保留清楚的实体短刀动作 | 克制的物理命中反馈，当前预览先不叠加特效 |
| 后续精良匕首 | 独立招牌动作与节奏，不能直接复用初始三连击 | 可辨识的专属轨迹/命中形状，控制持续亮度 |
| 后续稀有匕首 | 独立蓄力、出手与收招设计 | 特效跟随技能机制和刀刃轨迹，释放/命中分开 |
| 后续史诗匕首 | 能从剪影与动作阶段区分的招牌模组 | 更鲜明的分阶段特效，不能遮住手和武器 |
| 后续传说匕首 | 更醒目的专属攻击结构和终结姿势 | 招牌释放及终结特效，保持目标与伤害时点可读 |

同档多把武器可以有不同招牌技能；不把稀有度直接等同于一个全局动画ID。具体招式名称、机制和数量后续逐把确认，先完成初始匕首样本。

## 给程序方的资源与存档约定

- 查明当前初始装备对应的稳定武器模板ID，保留实例UID与存档。历史样稿的 w1/霓虹切刃称呼不能直接当作初始装备映射结论。
- 建议区分武器模板ID、品质、技能定义ID、技能动画ID、释放特效ID和命中特效ID。此为接口要求，非已完成的代码字段。
- 如果旧结构允许一个模板随机生成五种品质，需要明确以“模板+品质”解析招牌技能配置，或为不同招牌武器建立独立模板并限制适用档位。两种实现由程序方结合现有掉落与存档选定，不由美术擅自更改。
- 技能命中事件与表现分离；替换动作时重新校准事件时点，避免无命中姿势却先出伤害。
