## 1. 技能动作重做：一招 = 一小段连招（已完成，待你看效果）

**你的反馈**：技能动作太单调，有的还和武器不匹配（远程武器做砸的动作）。

**原因**：每个技能只有一个动作，人基本站着不动，全靠特效。Q 版大头身配小武器，只转转手臂，画面上几乎看不出变化。

**这次的做法**：每招 3～4 个分解动作，身体大幅移动 + 武器花活 + 多段命中，每一下都有顿帧、震屏。

### 新加的东西

- **动作表**（`Scripts/SkillMoves.cs`）：按"拍子"写整套姿势，一行一个时间点。以后改动作、加新技能只改这张表。
  - 新能力：转身（纸片转身）、绕腰空翻、武器抛起来再接、镜头推近、蓄能光、枪身抖、链子方向和长度、拍子事件（落地扬尘、滑步尘、抛壳、余电、冒气…）。
- **打击感**（`Scripts/Impact.cs`）：顿帧（命中瞬间战斗停一下，特效照常播，倍速时一起缩短）+ 震屏（只抖战斗画面，界面不抖）。
- **怪的反应**：被重击打中会弹起来，被电到会抖。
- **特效**（`WeaponFx`）：连锁电弧（拱起来一跳一跳）、蓄能电环、地裂、碎石、尘浪、掀地、抛壳、蒸汽、信号弹抛物线和红色爆炸、穿刺光、余电火花。
- **不匹配的问题**：
  - 武器外观只能套在同类武器上（近战配近战、远程配远程），不会再出现拿着枪做砸地。存着的外观换回同类武器时自动生效；衣柜 / 整备里类别不对的会提示。
  - 镜刃改用匕首的迅切连击，折光步枪改用贴脸轰击（招式和借来的外观对上）。

### 数值

技能时长从 0.7～0.95 秒拉长到 1.0～1.4 秒（放技能期间不普攻），所以倍率按"整个循环的伤害不变"重配了。模拟结果见下面第 2 节。

### 需要你拍板

1. 技能时长 1.0～1.4 秒会不会太长？挂机时每 4～5 下普攻就看一次连招。觉得拖可以整体压到 0.9～1.1 秒（动作表按比例缩，节奏不变）。
2. 震屏 / 顿帧的力度：现在最重的是震地（震 11 像素、停 0.11 秒）。
3. 动作风格：是不是你想要的"连招感"？哪招最不满意告诉我，优先改那招。

改了这些（按时间顺序）：

- **回刷规则**：被打倒后去最近的**普通关**刷（跳过 x-3 / x-6 精英和 x-7 首领）。原来是“退一关”，倒在 x-4 就去刷 x-3 精英、倒在首领就去刷 x-6 精英——精英一次要打 3～4 分钟还容易倒，有种子这样耗了几个小时。

- **线圈武器普攻会跳电**：线圈发射器、协议发射器打中目标后，电流跳到身后最近的一只怪，吃 50%（有一道小电弧，第二只怪会抖一下）。原来纯单体——协议发射器面板全游戏最高，模拟里拿着它的种子却全卡在第五章成群的波次。
- **首领叫来的小怪只有六成血**：原来和普通冲锋怪一样硬，单体武器在第五章首领战里三分之二的时间都在清小怪，打不死首领一直超时。

- **模拟玩家选武器时把“能不能打一群”算进去**（手炮 / 重锤 ×1.35、撞杆矛 ×1.3、霰弹 / 线圈 ×1.2）：真人看得出清怪快慢、卡关时会换群伤武器。原来只比面板，拿单体武器的种子常年卡在精英关第三波。

- 迅切连击改成 1 秒四段后，第一章各种子更集中了（0:33～0:48，中位数 0:40）。

### 发现的问题（需要你拍板）

**单体武器在成群的波次里明显吃亏。**同样的面板，拿手炮的种子过得去，拿单体武器（信号弩、吊臂钩索、气动钉枪、切割锯、霓虹切刃这几族）的会卡在精英关第三波。模拟里现在默认“真人会换群伤武器”，但玩家不一定知道该换。可选：

## 4. 机械飞升：义体升级（新功能，第一步）

### 傍晚：Windows 上的报错（CRLF 换行）

- 你在 Windows 上一进行动页就报 `FormatException`（`SkillMoves.cs` 解析技能动作表）。原因：Windows 的 git 把 `.cs` 签出成 `\r\n` 换行，动作表是写在代码里的多行文字，多出来的 `\r` 让空行解析数字失败（行尾的 `~lin`、`!事件名` 也会带上 `\r`）。Mac 是 `\n`，所以之前的测试都没撞上。
- 修好了：解析前先去掉 `\r`。冒烟测试加了一项：把动作表换成 `\r\n` 再解析一遍，结果必须和原样一致。游戏代码里只有这一处解析写在代码里的多行文字；别的读文本的地方本来就去掉了 `\r`。
