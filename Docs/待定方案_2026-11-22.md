## 3. 图鉴奖励

企划写的是「集齐一章的一套（5 个部位），给小幅永久加成和称号」。每章 25 件装备正好能分成 5 套（同一编号的武器 / 头 / 外套 / 背包 / 下装，比如第二章 6 号是「装卸工」那一套），一共 25 套。

| 方案 | 奖励 | 对节奏的影响 |
|---|---|---|
| A | 每集齐一套：攻击、生命各 +1%（最多 +25%） | 会让主线变快。第五章现在 1:45，离下限 1:41 很近，做完要重新调第五章 |
| B | 每集齐一套：一次性给核心（3 个）+ 织网碎片（10 个） | 不动主线节奏；核心在第四章起的突破用、碎片升义体 |
| C | 只在衣柜里标「已集齐」+ 集齐一章给个称号 | 不影响数值；但还没有称号系统，称号只能先显示在衣柜里 |

- **建议 B + C**：先不动已经调好的节奏，收集有实在的回报；以后想要更多成长再加 A。
- 衣柜里会多一个「套装」视图：每套 5 格，集齐了亮起来。

## 4. 新手提示（已做：按建议的 5 条，18:06 你说「继续做」以后）

- **建议**：不做强制教程，做 5 条只出现一次的提示，出现在合适的时候：
  1. 第一次进游戏：角色会自己打；鼠标移到屏幕边缘呼出终端。
  2. 第一次掉装备：去「整备」比较、穿上（导航上的数字是没看过的件数）。
  3. 第一次被打倒：没关系，会先回刷前面的关、变强了再自动挑战。
  4. 第一次进精英关：x-3、x-6 是精英，x-7 是首领。
  5. 第一次打败首领：回声层开放了（选关最下面）。
- 存在存档里，看过就不再出现；F9 清空测试存档会重新出现。不影响数值。

## 5. 展览模式（企划：「完整展览用流程」）

要先问你展览的情况：一台电脑？每个人玩多久？有没有人在旁边讲解？

- **我的初步建议**：设置里一个「展览模式」开关（或者启动参数），打开后：
  - 从一个准备好的存档开始（比如第三章开头、装备还行、装了两件义体），来的人几分钟内就能看到技能连招和首领；
  - 几分钟没人操作就自动重置回这个存档；
  - 关掉开发用的 F5 / F6 / F8 / F9。

## 7. Windows 打包

- 这台 Mac 的 Unity 没装 Windows 打包模块，打不了 Windows 版（macOS 版能打，已经验证 0 错误）。
- 二选一：在 Unity Hub 里给 6000.6.9f1 加装「Windows Build Support (Mono)」（要你自己点）；或者回 Windows 电脑上用 `Thread Zero → Build Windows`。
