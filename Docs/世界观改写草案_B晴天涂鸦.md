## 为什么要改

现在的剧情是暗的：主角得了治不好的病、城市被封锁、棚屋里的人「都不见了」、「每一根线缆都连着一个被回收的人」。
B 的画面是晴天、彩色涂鸦、Q 版，文字和画面会互相打架。

好消息：关卡的「往上爬」结构（沉降区 → 货运线 → 信号屋顶 → 镜面上城 → 织网）很适合亮色版，
背景照原构图重画也不用改关卡。要换的是「为什么爬」和「打的是谁」。

## 推荐方案 A：「机器人离家出走的夏天」

**一句话**：零号城的回收机器人一夜之间集体离家出走，城里的垃圾越堆越高。
回收社最年轻的回收员「零」，带着无人机小搭档，从城市最底层一路往上，把机器人一只只「打包」接回家，顺便查清楚它们为什么跑。

- **城市**：一座一层叠一层往上长的海边城市。越往上越新、越亮，最上面是云里的「织网」。
- **主角**：回收员 + 涂鸦客。脸上的面罩是**喷漆防护面罩**（不再是治病的维生面罩）。
- **敌人**：离家出走的回收机器人（就是之前样图里那批 Q 版机器人）。它们不是坏人，是在闹脾气；
  打倒 = 关机、打包、回收，倒下时冒星星打瞌睡，不会「死」。
- **开场三句**（替换「我的病没有药可治」）：
  城里的回收机器人，一夜之间全跑了。／垃圾堆成了山，只有回收社还在上班。／回收员编号：零。今天开始，把它们一只只接回家。

- **结局**：最深处没有敌人，只有一颗在呼吸的核心。零把最后一根线缆接上，零号醒了，第一次「听见」整座城
  （保留原来最好的一句：不是被吞没，是被听见了）。机器人回家，全城办了一场涂鸦节。
  零号问回收员下一道指令——「一起把城刷成彩色的。」
- **机械飞升**：名字保留，意思变成字面上的「飞上去」。五个首领核心改装成回收员的装备，
  不再是换肺换心脏：绞盘机械臂 → 调度护目镜 → 中继背架 → 冷核喷气背包 → 织网耳机。最后一阶段背包能飞。
- **三个服装品牌**（路锥俱乐部、信号鬼、投币帮）正好是城里的街头小队，不用改。
