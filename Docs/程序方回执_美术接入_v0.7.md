## 2. 接入改动

只动 `ThreadZero/Assets/Scripts`，界面布局、颜色、按钮没有变：

- 新增 `ActorView.cs`：整帧绘制，按脚底基准定位；缺图时返回 false，调用方退回旧绘制。
- `GameAppAction.cs`：角色改为整帧；帧切换由 `DollAnimation` 的攻击进度驱动（远程 举枪→开火→举枪→待机，近战 准备→举刃→突刺→准备），与伤害结算时机一致；敌人改用六张贴图；子弹从 ranged_fire 帧的枪口闪光处（实测画布像素 414,173）出发，不再使用 `PuppetGeometry.Muzzle`。
- `GameAppLoadout.cs`、`GameAppWardrobe.cs`、`GameApp.cs`：整备和衣柜的角色预览改为整帧。
- 未安装 `Integration/WholeFrameAssets.cs`，逻辑已并入 `ActorView.cs`（坐标改为走界面的缩放）。
- 未改 `PaperDollView / PuppetGeometry / CharacterView`，它们只在缺图时作为后备。

使用的 assetId：`c0–c4` × `idle / ranged_aim / ranged_fire / melee_ready / melee_windup / melee_strike`（通过图集）；`patrol / salvager / jammer / patrol_commander / furnace_foreman / blackout_broadcaster`。

**未验证**：这一轮的代码没有编译器可用，写完后只做了括号与调用检查；没有 Unity 内截图或视频。需要用户运行后提供。

## 3. 没有采用的部分

- **20 张图标（128×128）暂未使用。** 界面里图标最大显示到约 150 逻辑像素（1080p 下约 180 像素），128 会发糊；目前继续用旧 `EquipmentAtlas.png`（单件约 240 像素）。请按 256×256 重出，文件名不变。

| 优先级 | 内容 | 原因 |
