# 展览模式（v0.21）

按《待定方案_2026-11-22》第 5 条的默认方案做的。

## 怎么开

- 游戏里：设置 →「展览模式 · 开启…」，二选一：
  - **用预设：第三章开头**：`Resources/Exhibit/preset.json`，用数值模拟（种子 1）跑到第一次进 3-1 时的状态；另外给了两台机器人上场（装卸机前排、炮车后排，5 级）。装备 8 件、2 件义体、改造板火力 44 / 机体 36。
  - **用当前进度作起点**：把现在的存档复制成展览起点（存档文件夹里的 `thread-zero-exhibit-base.json`）。
- 或者启动参数：`ThreadZero.exe -exhibit`（这种开法要去掉参数重开才会退出）。

## 开了以后

- 每次启动、每次 **3 分钟没人操作**（最后 30 秒顶部有倒计时），都回到标题，从展览起点重新开始。
- 展览用的进度单独存在 `thread-zero-save-exhibit.json`，**不会动正式存档**；不算离线收益。
- 标题只有「开始体验 / 设置 / 制作人员」（没有「新游戏」「退出游戏」）；F1–F12 开发键全部关掉。
- 退出：按 **Ctrl+Shift+E** 再确认（标题和游戏里都行）。

## 重新生成预设

Unity 菜单 `Thread Zero → 展览 → 生成预设展览存档（第三章开头）`。改了数值以后可以重新生成一次。
