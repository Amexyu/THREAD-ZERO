# 给素材会话的任务清单 v0.12 · 分层部件（取代"整帧动作"路线）

> 来自程序/UI 会话（Claude）。2026-11-16。用户已看过离线原型 GIF 并同意往这个方向走。
> 请先读完本文，再动手画。**不要再扩展整帧 18 姿势方案。**

## 0. 为什么改

用户要求：装备种类会不断增加，换装后外观要变，并且要完全贴合动作。
整帧方案的工作量是「装备组合数 × 动作帧数」，装备 4 槽各 N 种就是 N⁴，画不完。
新方案是：**每件装备只画 1～3 张"单姿势部件图"，动作由程序用骨架关键帧驱动。**
工作量只随装备件数增长，换任意组合都能动。

此前"一动就分离/僵硬"的原因：部件是从一张成图上切下来的，没有重叠边、轮廓不统一。
所以这次部件要**一开始就按部件画**，不要从整身图里切。

先看效果：`Tools/RigPrototype/rig_attack.gif`、`rig_walk.gif`、`rig_idle.gif`
（三套装备，用同一套关键帧；画风是占位的几何图形，只看动作是否贴合）。

## 1. 与 v12 整帧匕首、v0.11 Q 版单姿势的关系

- v12 已做的 18 姿势整帧「迅切连击」：**保留，不再扩展**。后续只当作"技能演出"（大招/特写时整帧播放）的可选素材。普通走路、待机、普攻全部走分层部件。
- v0.11 的 Q 版单姿势（整体蹦跳、挤压拉伸）：思路保留，但"单姿势"现在是**每个部件各自一个单姿势**，不是整个角色一张图。
- 世界观（机械飞升）、Q 版基线《街头维生拾荒者》、机能风舍弃：以 `CharacterVisualBaseline_v12.md` 为准，不变。

## 2. 槽位 → 部件

游戏里 4 个装备槽，对应的部件如下（朝右的侧身视角）：

| 装备槽 | 要画的部件 | 说明 |
|---|---|---|
| 头部 | `head` | 含头盔/帽子/面罩，脸部造型一并画进去 |
| 护甲（身体） | `torso` + `arm`（近、远手臂可共用同一张）+ `legs` | 肩甲画在 `arm` 里，不画进 `torso` |
| 背部 | `pack` | 背包/罐/天线等 |
| 武器 | `weapon` | 只画武器本身，**不画手**（手由程序统一绘制） |

另有程序统一提供的"手"（拳头圆球）和地面阴影，素材方不用画。

## 3. 骨架与绘制顺序（程序侧，素材方只需知道）

```
root(脚底中心, 做整体蹦跳/挤压)
 ├ legs ×2 : 挂点 root 上方 24 单位, 左右各偏移 ±5, 绕腿顶锚点转
 └ torso   : 锚点=髋部, 挂在 root 上方 24 单位, 可前后倾
     ├ head : 挂点 torso 局部 (2, -38), 绕颈部锚点转(头比身体晚半拍, 有惯性)
     ├ pack : 挂点 torso 局部 (-22, -26), 绕附着点转(背部件滞后摇摆)
     ├ armN(近手) : 挂点 torso 局部 manifest.shoulder (默认 11,-33)
     │     └ hand → weapon（武器握在手上, 绕握把锚点转, 攻击时可沿杆方向前突）
     └ armF(远手) : 挂点 manifest.shoulderF (默认 -4,-33)
绘制顺序(后→前): pack, armF, legs远, legs近, torso, head, armN, weapon, hand
```

关键点：
- 单位：**1 单位 = 交付 PNG 的 4 像素**（manifest 里的 `scale`，默认 4）。下面的尺寸都是"单位"，实际像素 ×4。
- 角度：手臂/腿/武器"垂直向下"是 0°，朝前摆为正。
- 所有部件都画成**静止站立时的单姿势**：腿直立、手臂自然下垂、武器画成**从握把向下**延伸（尖端在最下方）。程序负责转到别的角度。
- 手点：手臂图**底边往上 11 单位**处是手的中心（`arm` 底部 11 单位留给手套/拳头区域，不要在那里画武器细节）。

## 4. 部件规格表（单位，交付像素 = 单位 × 4）

| 部件 | 尺寸范围（宽×高） | 锚点（pivot，单位，原点在图左上） | 备注 |
|---|---|---|---|
| `head` | 80–96 × 70–86 | 底部中心：x≈宽/2(±8)，y∈[高-12, 高-4] | 锚点在颈部，头下沿会被躯干盖住 |
| `torso` | 50–68 × 44–58 | 髋部：x≈宽/2(±6)，y∈[高-6, 高-1] | 肩宽不要超过 68 |
| `arm` | 18–36 × 42–58 | 肩部：x≈宽/2(±4)，y∈[5, 13] | 手臂上端必须延伸盖住肩关节；肩甲画在这里 |
| `legs` | 24–32 × 30–38 | 髋部：x∈[8, 12]，y∈[2, 6] | 脚尖朝右(+x)，靴子在下端 |
| `pack` | 24–44 × 46–68 | 附着点：x∈[宽-10, 宽-2]，y∈[0.5高-4, 0.85高] | 附着点在朝向身体的一侧 |
| `weapon` | 10–40 × 60–140 | 握把：x≈宽/2(±5)，y∈[2, 45] | 必须在 manifest 里给 `tip`（尖端坐标） |

以上范围与 `validate_parts.py` 一致，**以脚本为准**。参考样例在 `Tools/RigPrototype/sample_parts/{A,B,C}`。

## 5. 画法硬规则

1. **每个部件一张独立 PNG，RGBA，透明背景，四周至少留 0.5 单位（2 px）透明边**，不要被画布裁切。
2. **关节处必须画重叠**：手臂上端、腿顶端、武器握把处要延伸到关节中心之外至少 3 单位，且被盖住的部分用主色块填满。转动时才不会露缝。校验脚本会检查锚点周围是否不透明。
3. **统一描边**：深墨色 `#121416`，粗约 2 单位（8 px），所有部件同一粗细。
4. 光源左上；**不要画投影**；不要把别的部件画进来（不画手、不画身体、不画武器在身上的一部分）。
5. 肩甲属于 `arm`，背包带属于 `pack`，头部的面罩/护目镜属于 `head`。
6. 同一件装备的稀有度变体（灰/绿/蓝/紫/金/红）：**同尺寸同锚点，只换颜色和细节**，这样程序可以直接换图。
7. 武器必须**朝下画**（握把在上、尖端在下）。程序会旋转它。

## 6. 交付格式：parts.json

每套装备（一个"组合"）一个文件夹 + 一个 `parts.json`：

```json
{
  "scale": 4,
  "weapon_class": "dagger",
  "shoulder": [11, -33],
  "shoulderF": [-4, -33],
  "parts": {
    "head":   {"file": "head.png",   "pivot": [48, 76]},
    "torso":  {"file": "torso.png",  "pivot": [34, 54]},
    "arm":    {"file": "arm.png",    "pivot": [12, 9]},
    "legs":   {"file": "legs.png",   "pivot": [12, 6]},
    "pack":   {"file": "pack.png",   "pivot": [26, 42]},
    "weapon": {"file": "weapon.png", "pivot": [12, 8], "tip": [12, 74]}
  }
}
```

- 所有坐标是**单位**（含透明边在内的整张图）。参考 `sample_parts/A/parts.json`。
- `weapon_class` 可选：`dagger / spear / hammer / gun / sword / shield / other`。攻击动作由它决定，不用美术画。
- 如果护甲有独立的远手，可以多给一个 `armF`；没有则近远手共用 `arm`。

## 7. 动作由程序负责（素材方不用画）

待机（呼吸蹦跳）、走路（单脚落地挤压）、攻击（按武器类型：短刃连刺 / 长枪前突 / 巨锤举砸）、斩击拖尾、受击、死亡淡出，都由 `rig.py` 里的 `pose()` 关键帧驱动。
素材方只管把部件画对。想要某个动作更好看，是改关键帧，不是重画图。

## 8. 验收流程（每套装备都要走一遍）

```
python Tools/RigPrototype/validate_parts.py <套装文件夹>/parts.json     # 必须"全部通过"
python Tools/RigPrototype/rig.py <输出目录> <套装文件夹>/parts.json      # 生成待机/走路/攻击 GIF
```

然后把**生成的三个 GIF**（不是单张图）发给用户确认。看以下几点：
- 头/手臂/背部件有没有脱离、露缝；
- 武器握法是否自然（拳头盖在握把上）；
- 肩甲随手臂转动是否穿帮；
- 不同稀有度、不同组合换上后是否仍然贴合。

通过后才进游戏。程序侧接入由我（Claude）做。

## 9. 本轮要交的东西（按顺序，做完一项给用户看一次）

1. **新手装一整套**（贴合现有 Q 版基线《街头维生拾荒者》）：`head` ×1、`torso+arm+legs` ×1、`pack` ×1、`weapon`=匕首 ×1。走 §8 流程。
2. **第二套差异明显的重装**：重甲 + 长枪（用来验证"不同体型/武器也能共用关键帧"）。
3. 以上两套通过后，再各给 1 个替换件（比如换头、换武器），验证混搭。
4. 之后才扩展到更多装备和稀有度变体。

> 注意：不要先批量画一大堆。先把第 1 步做通、让用户确认动作贴合，再放量。

## 10. 已知限制（不要为这些改图）

- 手臂目前是整根摆动，没有肘部屈伸。要不要拆成上臂+前臂，等第 1 步素材回来再定。
- 动作是刚体拼接，不会像逐帧手绘那么顺滑；靠光效、残影、顿帧补质感。
- 占位样例的画风不是目标画风，只参考规格。
