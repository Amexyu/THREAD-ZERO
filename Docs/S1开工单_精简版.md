# S1 开工单（精简版，给素材会话）

日期：2026-11-16。**只读这一份 + `Deliverables/ArtPack_v13/Review/s0_character.png`（1 张）就能开工。**
不要为了"了解背景"去读其他文档或打开 GIF/大图，对话长度有限，先做事。需要细节时再按下面"需要时再查"的路径单独读。

## 任务
画一套**新手装的分层部件**（单姿势、透明 PNG），让程序用骨架驱动动作。造型以 `s0_character.png` 为准（灰发、遮面面屏与呼吸器、黑夹克、浅灰靴、肩部护片、青绿识别条），按 Q 版比例画成**独立部件**。

## 要交的部件（每个一张 PNG，RGBA，四周留 ≥2px 透明边）
`head` / `torso`（空手，不拿武器）/ `arm` / `hand`（握拳黑手套）/ `leg_near` / `leg_far` / `pack`（b0 折叠回收背包）/ `weapon`（w1 匕首，握把朝上、刃尖朝下）

## 尺寸与锚点（1 单位 = 4 像素；锚点 pivot 单位同，原点左上）
| 部件 | 尺寸范围（宽×高） | 锚点 |
|---|---|---|
| head | 88–110 × 76–96 | 颈部：x≈宽/2(±8)，y∈[高-12, 高-4] |
| torso | 46–68 × 34–50 | 髋部：x≈宽/2(±6)，y∈[高-6, 高-1] |
| arm | 18–36 × 32–44 | 肩部：x≈宽/2(±4)，y∈[5, 13]；手点在图底边上方 11 单位 |
| hand | 约 16–20 × 16–20 | 手心（图中心） |
| leg_near / leg_far | 28–38 × 24–34 | 髋部：x∈[8,16]，y∈[2,7] |
| pack | 22–44 × 40–62 | 附着点：x∈[宽-10, 宽-2]，y∈[0.5高-4, 0.85高] |
| weapon | 10–40 × 60–140 | 握把：x≈宽/2(±5)，y∈[2,45]；必须给 tip（刃尖坐标） |

## 画法硬规则
1. 每个部件单独画、同一比例；不要从整身图里切。
2. **关节处画重叠**（手臂上端、腿顶端、武器握把处，延伸出关节中心 ≥3 单位，用主色填满），转动才不会露缝。
3. 统一深墨描边（约 2 单位）；一层硬边阴影；**不要渐变、排线、发光**。
4. **细节降级**：头发合并成几大束，口袋和扣件合计 ≤3 处，缩到 64px 仍能认出轮廓。
5. 头要画完整（含后脑）；呼吸管只画到颈侧进领口，不连背包。
6. 稀有度变体以后只换色，同尺寸同锚点。
