## 动画选择

采用**分层部件＋程序变换动画**，暂不引入额外骨骼动画软件或付费工具。

| 状态 | 第一阶段做法 | 换装共用方式 |
|---|---|---|
| 待机 | 极小幅度呼吸起伏 | 所有已穿部件共用根变换 |
| 攻击 | 独立普攻事件触发，远程0.22秒/近战0.34秒 | 所有武器共用握持点，动作结束归零 |
| 受击 | 短促位置扰动、偏红反馈 | 部件共同响应，复用原图 |
| 推进突袭 | 战场中的前冲位置变化与残影线 | 整个角色共用位移 |
| 维修/倒地 | 角色变暗、压低 | 保留装备，不重新画死亡帧 |
| 无人机 | 分离图集部件，轻微悬浮与射线 | 独立于角色衣服，不带动角色骨架 |

当前为固定战斗位置的挂机原型，未制作完整走路循环、骨骼蒙皮和逐帧腿部动画。需要长距离行走时，应先拆分腿、手臂或补少量行走帧，而不是把静态站姿平移冒充走路。

第一阶段先确保待机和短动作不穿帮，后面可逐步加入头/躯干/手臂/腿的标准骨架。装备数据、衣柜和掉落不依赖动画方式，不需要随动画升级重写。

DollAnimation.cs将时间推进与绘制分开，重复绘制不重触发动作；暂停冻结计时。无人机射击不会触发玩家后坐。呼吸围绕脚底枢轴微缩放，受击扰动幅度不超过1.5逻辑像素，远程武器旋转峰值11度、近战58度。换装备与换街区清除旧动作。

同时修正场景生成脚本的MainCamera标记，避免运行时因找不到主相机而再创建一台相机及AudioListener；实际Unity运行仍待验证。

## 视觉验收清单

1. 兜帽开口露出脸，不能盖黑面；发丝可在外沿保留。
2. 外套袖口与素体手的位置一致，肩膀与裤腰不露缝。
3. 背包在身体后方，不能盖住胸前装备。
4. 手枪握把贴近右手，后坐旋转不会穿过前臂。
5. 各部位辉光贴在对应设备上，幻化不改变装备品质。
6. 攻击、受击、突袭和维修结束后回到正确基础姿势。
7. 小窗口与放大预览中都能识别衣服、武器和背包。
