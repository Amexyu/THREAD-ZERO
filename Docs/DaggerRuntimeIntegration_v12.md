# 初始匕首运行接入

2026-11-16。用户已认可十八姿势修订版的动作方向，随后要求制作并接入。用户此次明确授权优先于旧 v0.11 任务清单中“不要修改程序”的分工限制；UI布局和交互没有重做。

## 接入范围

- 现有 `w1` 的 Common（当前界面称“民用”）实例作为首把/初始匕首样本。开局武器仍是原来的 w0，不改旧存档或强行替换玩家装备。
- 三连击只用于这档匕首：0.23、0.32、0.51秒分别结算80%攻击力的技能伤害，5秒冷却。冷却期间用0.35秒的单次短刺普攻，命中0.14秒。
- 目标死亡后取消剩余段，换装或维修时重置；与普攻互斥，攻速不能把下一次普攻挤进技能。技能不推进三次普攻电弧计数，也不叠加旧普攻专用处决倍率；汲取仍由共用实际伤害入口处理。
- 透明绘制样本限定 c0 外套、默认灰发遮面头、b0背部、w1实际与外观、Common品质。不能用固定整套图掩盖其它装备的真实外观；不匹配时保留旧绘制。
- 行进沿用整体小幅蹦跳，攻击播放十八个绘制姿势。不是骨骼动画。

## 查看方式

- Unity：打开 Main 场景，选择 `Thread Zero > Review Starter Dagger (Unsaved)`，进入不读写正式存档的测试局。
- 双击根目录 `ReviewStarterDagger.cmd`：在用户的正常桌面会话启动本机Unity，打开当前源码工程并进入隔离测试局；若Unity已经打开，则在其中选择上述菜单。不是预先打包的exe。测试局仅在内存里配上普通 w1 和这套衣服，退出后恢复原存档。
- 正常游戏：实际穿戴 Common w1，清除武器幻化，头部卸下且清除头部幻化，外套c0/背部b0，即使用新图。其它品质不能获得这套三连击。

## 素材交付的实际状态

`Assets/Resources/Art/V12/StarterDagger/Body.png` 与 `Weapon.png` 同画布、同帧索引叠合，避免手和刀各自变换导致脱离。18格256×256，图集1536×768；脚底基准(128,238)。实际alpha透明背景已检查，并在浅深两种底色对照。

需要明确：这次只将当前十八姿势图按像素划分为完整套装与露出的刀刃层。手中被遮住的刀柄仍保留在握持处，`Weapon.png` 不是一把带完整握柄的独立物品图；头、外套、背部也没有达到四槽自由替换的分层标准。该接入用于验证用户认可动作在游戏中的效果，不能称为通用换装骨骼或完整模块化量产管线。后续需补完整独立装备与被遮挡身体绘制，再扩展其它外观。

## 代码与验收

- `DaggerSkill.cs`：纯C#时间轴与三段伤害调度。
- `DaggerActorView.cs`：符合外观条件时绘制两张透明图集；行动、整备、衣柜预览使用同一入口。
- `GameAppDaggerReview.cs`：隔离测试局与自动运行截图，不写正式存档。
- `CombatSession.cs`：接入时间轴，中断/击杀时终止剩余段。
- `Tools/TestDaggerSkill.ps1`、`Tools/TestModel.ps1`、`Tools/CompileSources.ps1`：验证入口。旧模型测试关于开局四槽全穿戴的过时断言改为当前默认头空槽的预期，没有修改实际开局装备规则。

更高稀有度的独特技能动作与特效仍按 `DaggerSkillProduction_v12.md` 逐件制作，当前没有将三连击复制给高品质装备。
