# 音乐与音效：来源与授权（v0.21，11-24 更新音效）

用户 11-22 21:32：「音乐和音效都去免费的网站找」。只用 **CC0（公共领域）**、不用注册账号就能下载的素材；不需要署名，但照样列在随包的 `StreamingAssets/Licenses/第三方授权_Third-Party.txt` 里（11-24 去掉了「制作人员」页）。
下载经 Chrome（存到 `Gemini/_收件箱/出图/`，原文件不进提交），处理在设备虚拟机的 `$HOME/audio_raw`（ffmpeg：音乐响度统一到 −18 LUFS、首尾 0.5 / 2 秒淡入淡出、Vorbis q4；音效峰值统一、Vorbis q5）。

选曲只看了曲名、速度和响度（这边没法试听）：**请你实际听一遍**，哪首不合适告诉我换（同一个包里还有 Welcome Mix、Jumping Cyborg、System Overload、The Casino、Caves、Currents 等可选）。

游戏里怎么用：`GameAudio.cs`（两条音轨交叉淡化 1.6 秒；按场景换曲：标题 / 开场 / 尾声、每章、首领关、零号深网），音效挂在按钮、开火、命中、挨打、护盾、机器人等事件上，同一个音效有最短间隔；设置里音乐 / 音效各 5 档。

## 11-24 音效试听（第一轮）

用户 11-24 18:09 反馈「音效不太匹配」，特别是电流武器开火像激光。做了试听页（每个事件 A / B / C 三个候选），18:27 的结果：

- 选中并已换进游戏：短铳 / 霰枪 / 步枪开火 = A、刀刃打中 = A、重锤打中 = C、长杆打中 = C（命中声按近战武器的种类分开：`GameApp.HitSound`）。
- 都不要（要真实录音，等第二轮）：电流开火、钉枪 / 干扰枪开火、手炮开火、钩索 / 链鞭打中、机器人开炮。目前仍用原来的音效。
- 敌人倒下：没选，保持原样。
- 第二轮打算用的 CC0 素材（需要用户同意后经 Chrome 下载）：opengameart「Electricity Game Sound Pack」（faxcorp）、「Gunshots」（kurt）；钉枪和链条还没找到合适的 CC0 录音。
- 生成脚本：`Gemini/_tmp/sfx/gen.py`（候选）、`export_round1.py`（导出到游戏，响度对齐原来同类音效；不进提交）。
