# 给 GPT 的任务卡（v0.14，每张卡开一个新对话）

**用法**：每次新开对话，只发“通用规则”+ 一张卡。不要让它读整个仓库或旧文档；做完一张卡就结束对话，把结果写进 `Deliverables/ArtPack_v14/RECEIPT.md`。
**对话里少贴图**：图片最占上限。需要参考图时只给文件路径，让它自己打开，一次最多 1～2 张。

- 项目：THREAD ZERO，Q 版放置战斗。仓库 `F:\毕业制作\THREAD-ZERO`。
