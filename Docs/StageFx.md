# 背景动效（StageFx）

静态分层背景上叠一层会动的东西：灯的呼吸和偶尔闪烁、水面反光、滴水、蒸汽、会动的道具（水泵阀门轮转、压力表指针抖）。
代码：`ThreadZero/Assets/Scripts/StageFx.cs`，在 `StageArt.Background` 里每画完一层就画这一层的动效。

## 配置

每个场景一份 `<场景字母>_fx.json`，和背景图放在同一个文件夹（如 `Resources/Art/V16/Stage/C_fx.json`）。没有配置的场景就没有动效。

- `layer`：0 远景、1 中景、2 地面。
- 灯、水面、滴水、蒸汽的位置是该层图片里的比例坐标 `u`（横）、`v`（竖），跟着那一层一起卷动。
- `lamps`：`u, v` 灯泡位置，`r` 光照区半径（按图层高度的比例），`color` 可选（不填是暖白灯泡；控制台屏幕这类填青色）。
- `water`：`v0..v1` 水面所在高度范围，`count` 反光线条数。反光按 1700 像素宽分布，不跟着窄的地面图重复。
- `drips`：`u, v` 管口，`fall` 落下距离，`every` 间隔秒。每张平铺只有约三成位置会滴，时间各自错开。
- `steam`：`u, v` 出汽口，`every` 间隔秒。
- `props`：会动的道具，按逻辑像素间隔摆放（`x0` 第一台位置、`spacing` 间隔，都是这一层卷动坐标），不会跟着图层平铺重复，也不会被接缝切断。
  `baseV` 底部高度、`height` 道具高度（按图层高度的比例）；`wheelU/V/Size/Speed` 阀门轮；`hubR` 轮子后面盖住原图轴座的圆；`gaugeU/V/R` 压力表指针（`gaugeU < 0` 表示没有）。

- `flows`（v0.18）：落水 / 水帘。`u0..u1 × v0..v1` 水帘范围，`count` 往下流的亮纹条数，`speed` 流速（图层高度 / 秒），底部带一串水花。
- `blinks`（v0.18）：指示灯，硬边圆点亮灭。`r` 半径，`period` 周期秒，`duty` 亮的比例，`phase` 相位（0..1，用来让红绿灯交替），`color` 亮时颜色（`{"r":1,"g":.3,"b":.2,"a":1}`）。
- `windows`（v0.18）：亮着的窗，`u0..u1 × v0..v1` 窗玻璃范围，大约每 `every` 秒有人影走过（暖色暗影，裁在窗框里）。
- `rain`（v0.18）：整屏斜雨，画在这一层上面。`count` 根数，`angle` 倾斜角，`speed` 下落速度，`len` 长度，`width` 粗细，`alpha` 不透明度，`v1` 落到这一层的哪里为止。按卡22的规则雨只放远景层（`layer: 0`）。
- `water` 新增可选 `color`（`a = 0` 用默认青白色），用来做暖色的窗户倒影。
- `props` 新增运动：`motion` 为 `swing`（绕 `pivotU/pivotV` 摆 `amp` 度）、`slide`（左右来回 `amp` 逻辑像素）、`lift`（往下放 `amp` 逻辑像素再收回），`period` 一个来回的秒数。阀门轮 `wheelSpeed: 0` 就是不转（每台角度不同）。
- 首领场地（D）的远景不卷动，也能挂动效：`StageFx.DrawCover` 按铺满的矩形算坐标，不平铺；道具在首领场地不画。

## 样板流程

1. 新素材先放 `Resources/Art/V16/StageProto/`（同名：`C_far / C_mid / C_ground / C_fx.json` 加道具图）。
2. 测试剧本里 `set StageArt.ProtoFolder Art/V16/StageProto/`，第一章同字母的场景就改用样板，正式素材不动。
3. `burst` 连拍拼 GIF 检查，确认后把文件挪进 `Stage/` 替换正式素材。

## 素材处理脚本（`Tools/bg/`）

- `bg.py`：一整套 A–D 的品红抠图、横向无缝、地面对齐和同框预览。
- `bg_c.py`：只处理单个场景（C）并和其他场景拼同框预览。
- `stage_proto.py`：把处理好的层缩到 2048 宽放进 StageProto，并自动找出中景里灯的位置。
- `bg_scene.py`：处理单个场景（`<S>_far_原图 / _mid_原图 / _ground_原图`，有 `_净.png` 手工清理副本就优先用），出 2048 宽的抠好图和同框预览；`--ch2` 用第二章敌人摆预览，`--keyhard` 中景里有被品红染过的远处结构时抠得更狠；地面还没出时预览先用游戏里现有的地面。
- `despill.py`：去掉抠图边缘残留的品红色偏（只动离透明区几像素内的边缘，正常颜色不受影响）。
- `fx_scan.py` / `crop_grid.py`：找图层里的亮点、裁一块画细网格，用来写动效坐标。`fx_scan.py Stage3 ABCD` 只扫指定文件夹。
- `fx_dots.py <层.png> [red|cyan|warm]`：找图层里的小色点（天线顶的红灯、机柜的青色状态灯、暖色窗户），打印比例坐标，直接抄进 `blinks / lamps / windows`。
- `pose_sheet.py <三姿势图> <怪名> <参考怪> [--fit] [--height N]`：敌人三姿势切成 512 的 idle / windup / strike。默认会抹掉隔壁格漏进来的碎片；`--fit` 有姿势伸出画布（举过头顶的盾）时整体缩小放进去；`--height N` 参考怪形状差太多（扁的运输母机 vs 高的中继舱）时直接给 idle 高度。
- `flip_columns.py <三姿势原图>`：Gemini 画成朝右时，三格各自水平翻转，另存 `_朝左.png`（原图不动）。

## Gemini 网页版出分层图的已知毛病

- 让它把空白处填品红，它经常不填：中景会整张不透明，地面层只在走道上沿画一条品红线（可以拿这条线当切割线）。
- 单独物件放在纯品红底上通常没问题；但有时会把物件贴在上一张图的背景上，要用洪水填充加手工挡区域抠出来。
- 「下载完整尺寸」得到的是 2752×1536 的 JPEG。
- 灯头周围会画一圈被品红染过的半透明光晕，抠完是一圈红晕：`bg_scene.py` 会把半透明偏红的像素挖掉。
- 有时会把上一张远景的一块（带柔边）贴进中景里：用 `_净.png` 副本把那块涂成品红再抠。
- 网页版额度（Pro 方案，用量页 gemini.google.com/usage）：按约 5 小时一个时段算，另有每周上限；高级模型更耗额度。2026-11-21 一个时段出了约 15 张图就用满，每周上限只用了 12%。
- 省额度的做法：出图用「日常帮助」模式（先试一张看画风）；会动的道具几件拼一张出再切开；怪物的待机 / 前摇 / 出手三个姿势拼一张出；地面层能沿用就沿用（调色即可）。
